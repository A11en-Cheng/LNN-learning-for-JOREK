# 0018 椭圆代理（ψ,u,几何 → Z_j,omega）

Blocked by: #0001, #0017

目标：预训练一个图神经网络代理，学习 `(ψ, u, 几何) → (Z_j, omega)`，用记录值作 ground truth，
替代不可靠的局部解析 `Δ*`/`Δ`。这是"神经算子替代椭圆求解"方向的具体落地，也是把二阶椭圆量
可靠喂回 #0017 物理残差的必要步骤。

交付：GNN（复用现有 GAT 层）或节点局部 MLP + 几何特征；在 train/val split 上逐场报 R²/RMSE；
与记录 Z_j/omega 的逐节点相关 >0.9；cost 与参数规模报告。

验收：val 上 Z_j 与 omega 的 R² >0.9（或至少显著高于当前局部算子的 0.25/0.81）；接入 #0017 后
物理残差项量级合理、无 NaN。
