# 含源自主两步 AR 训练试验（2026-10-09）

## 任务与实际预算

用户授权双 phaseA 冒烟后训练，并要求预测段不得保留真实 Ψ 或其它场回授。
两组完整云自主冒烟已通过，见 [冒烟报告](native-autonomous-smoke-2026-10-09.md)。

本轮采用明确的小预算：seed=1、Adam lr=1e-4、每 run 一次两步 AR 更新，共两次；不是正式收敛训练。
先固定评估随机流测训练前误差，v400 更新后保存，以全新模型/源/初态构造器恢复，再进行 inner 更新和训练后评估。
burn-in=0 仅为这次机制试验设置，**没有据此选定 burn-in 基线**；尚未做正式课程、长程 AR 或跳步训练。
预留 val/test 窗口仅做过数据资格审计，本轮不评估、不拟合其统计，不报告泛化结论。

## 接口与防泄漏

- `tools/train_native_autonomous_pilot.py`：`PilotWindow`、`PilotTrainer.update/evaluate/save/load`。
- `tools/run_native_autonomous_pilot.py`：固定预算真实执行入口，检查两组匹配的自主 smoke 证据。
- 全部九场残差预测、双源、marker 云、shard、非局部诊断、历史与时间状态走实际完整事件接口。
- 初始化后不安装任何真实场；先完成两个连续预测事件，随后用标签计算 loss/metrics。
- 禁止 RecordedPsiFeedback / teacher shard、带真实场干预标记的状态，以及非 train 拟合窗口。
- 两个 run 共用 **3147 个可学习参数**；各自几何、源与时间原点 buffers 保持独立。
- train-only 缩放只拟合两个训练初态的完整 U/rawD 及对应 Gauss 值/梯度/条件参数，未使用 val/test。
- 源通道仍用声明过的物理参考尺度，不将其冒称统计拟合。
- 每个评估 run 固定独立随机流（seed 1、2），结束后恢复训练 RNG，保证训练前后出生随机流可比。

loss 复用既有 `native_supervision`：原生系数、原始流体历史增量、Gauss 值、兼容一阶梯度四项权重均为 1；各项按训练统计缩放后均分聚合。
指标复用 `recorded_supervision`：逐场/degree/梯度/历史、五个投影通道、真实半径对应存活标志的固定 ID shard 位置，分别输出相对 L2 和 Pearson。
源监督标签使用事件起点 P[n]，九场及 shard 标签使用事件终点 U[n+1]；不把相邻文件名当成同一时刻。

NumPy 源、shard、平衡诊断为 stop-gradient；反传覆盖 Torch 联合场/CfC 的两步路径。
源/位置误差是诊断指标，不宣称这些 NumPy 误差直接参与端到端反传。

## 检查点与测试

checkpoint 保存共享 parameters、每 run 独立 buffers、模型模式、Adam、完整 Python/NumPy/Torch RNG、缩放、split/config、controls 及完整初态 digest。
这是 **完成一个训练窗口后的更新边界恢复**：下一窗口重新载入其认证初态，不是中途 marker 子步或 AR 窗口恢复。
原有完整物理状态检查点机制未移除。

专项测试 **11 passed**：真实公共小网格完整事件上的优化更新、非零有限梯度、输入初态不变、共享参数且 buffers 独立、下一更新精确恢复、固定评估 RNG、teacher/split 拒绝、源标签时序和真实 shard liveness。
独立 review 发现的 `term_lambda` 等 run 专属 buffers 漏存问题已在实际执行前修复并复验。

## 实际执行结果

**成功完成两次真实更新及新构造器恢复**。总 wall **546.492 秒**，观测峰值 RSS **3.065 GB**。
预评估、训练和后评估共记录 12 个完整 base 耦合事件。两 run 后评估中，第一步预测场 digest 与第二步输入场 digest 精确相同。
没有真实场回授、额外更新或超参搜索；没有泛化或收敛验收。

固定评估随机流下的两步平均联合 loss：

|run|训练前|两次共享参数更新后|相对变化|

v400/inner 实际更新梯度范数分别为 `1.9760378187905447e-4`、`0.054090942430076325`。

最终 Adam 每个状态的 step=2；第二次更新改变了 3147 个参数中的 2947 个系数，两个 run 的 buffers 在优化更新前后保持逐位相同。
