# 原生窗口、兼容梯度、参数条件化与 CfC 课程设计（2026-10-08）

状态：用户确认的方向与待实现契约，依据 ADR-0021；不是训练结果。物理迭代与初始化继续按 ADR-0019/0020。使用 codebase-design 将可替换时间核心放在已有场步 Interface 内，使用 domain-modeling 区分物理状态、派生梯度、学习记忆和教师替换。

## 1. 现有能力与本轮核查

- `native_field_step.py` 的当前核心是 77 维输入（36 个场系数 + 36 个原始历史 + 5 个时间特征）→ tanh → Richardson 节点 stencil → 36 个本步系数增量；不是 CfC，也不调用旧 `LTCFieldStep`。
- 支持 H=1 全 degree、Torch 单步反向、共享 index 更新、模型续跑。节点 P1/lumped stencil 与共享 index 均值是已登记学习近似，不是原生 cubic 全 degree 空间算子。
- `reference_solver` 以 no_grad/NumPy 提交，仅支持显式零反馈/零投影历史；没有物理参数条件化、显式原生梯度输入、CfC 隐状态或可微多步事件驱动。`learned_unverified` 不等于执行物理 BC。
- 依据 [场步报告](native-joint-field-step-2026-10-08.md)、[状态报告](native-state-fidelity-resume-2026-10-08.md)、[原生求值报告](native-gauss-local-marker-loads-2026-10-08.md)。保留上述已有实现，不把本轮路线修订变成重写。

## 2. 窗口：先划分，再切片

先按 run/restart segment 划分训练/验证/测试；同 run 时间块间隔离完整窗口支撑（包括初始化回放、warm-up 和目标），不允许重叠原始帧跨 split。归一化统计只由训练 split 拟合并保存版本。一个 run 中参数恒定不提供该参数变化的辨识证据；跨 run 泛化与同 run 时间预测分开报告。

设预测起点 n、warm-up 长度 L、目标步数 K；窗口完整支撑为 n-L 到 n+K。默认不跨 JOREK restart、网格/模式/单位不兼容变化；普通步长变化应保留。物理参数跳变默认切分，显式时变控制需单独声明因果可用计划。普通训练 chunk 不触发程序 restart，不清物理状态。

| 对象 | 单窗口逻辑布局 | 可用性与所有权 |
|---|---|---|
| 完整场与原始流体历史 | `[L+K+1,9,4,H,N]` 各一份 | warm-up/current 是观测；未来项只作标签或显式 teacher-forcing 输入。D_u 不由舍入端点差替代 |
| 五通道反馈及原始历史 | `[L+K+1,5,4,H,N]`（按实际事件可用性及 mask） | S_n 驱动 U_n→U_{n+1}；D_S 缺失必须拒绝相应消费任务，不能补零。只有具备来源证据的恢复方法才可用 |
| 网格上下文 | 原生 x/size/vertex/index/模式/约束 | 同网格共享，不逐时间复制；含单位、BC/config 指纹 |
| 值与一阶梯度 | 单步单元 Gauss 布局 `[E,Q,9]` 及 `[E,Q,9,2]`（H=1） | 从该步实际输入的完整系数求值；教师场被预测场替代后必须重新计算，不能沿用真实未来梯度 |
| 物理参数 | 静态分组向量 + 可选逐步已知控制 | 每项带来源、单位、有效时间、消费者；ID/输出计数不作物理特征 |
| 时间 | 每事件当前/前 dt、格式、端点时间、source gather time、标志 | 输入时间计划由运行控制提供，不能读未来目标反推推理步长；采样窗口长度不冒充流体 dt |
| 初始化与状态资格 | 原生 checkpoint 锚点、匹配 marker/shard/反馈/时钟及回放计划 | 标注 `field_supervised` 或 `coupled_rollout` 资格；缺 marker 初态的窗口不能假装具备耦合资格 |
| 训练控制 | teacher masks、loss masks、warm-up、horizon、detach/truncation 计划 | 不是物理输入；保存随机种子与采样策略 |

批维 B 加在最前；不同网格不得不带映射直接堆叠。不同 dt 可逐样本执行或按计划分桶，再实现有明确语义的向量化；不默认现有标量 dt Interface 支持任意异步 batch。

数据集可以持有未来标签，但模型步 Interface 只接当前准许输入；推理视图不暴露标签访问器。用“改写未来标签不改变首步输入/输出”、时间错配拒绝、同号投影配对、split 支撑互斥测试防泄漏。

### 稀疏 marker 与启动

逐步流体输出不代表每步都有完整 marker 快照或投影历史。耦合窗口从匹配 checkpoint 一次初始化并因果回放到预测起点；必要 warm-up 的教师场仅取预测起点以前。费用计入数据准备/推理成本。不能在每个训练步读真实 marker 重置云。缺少可恢复初态时可做明确的场监督窗口，不得标记为 C0。

注册 restart 的重复流体输出不是零时长粒子窗口：训练默认切开；专门事件测试按 ADR-0020 执行零投影 startup 后正时长采样。模型恢复和 truncated-BPTT 切点不触发 startup。

## 3. 零阶与一阶：同一场的兼容观察

对固定原生几何，用同一系数 C 计算 `u_q=B_q C`、`grad_q=G_q C`。B/G 包含源码核实的 signed size、模式、几何导数变换；不把 degree1/2/3 当普通物理偏导。完整 C 通过状态 skip 保存，额外 Gauss 特征不能替代它。

1. 在原生单位中求值/求导，再按 field/量纲分别缩放特征；不要先对系数逐项非线性变换再假称其导数是原物理梯度。若采用非线性场变换，显式执行链式法则及逆变换。
2. 梯度 R/Z 分量方向、局部坐标方向、坐标谐波与物理单位全部显式。原生系数可带符号；不能对高阶密度/温度系数做正值截断。
3. Gauss/单元特征若要回到节点或唯一自由度，必须定义 gather/scatter、权重和共享 index 规则。附加特征聚合可以降维，但需登记近似；不能将弱式载荷、原生系数与 latent 特征互当。
4. 解码只生成一份兼容的完整原生场/增量，再从其求导。共享 DOF、轴/悬挂约束、物理 BC 由统一更新映射处理；未知分支拒绝，不能用节点统一冻结冒充。
5. 数据损失可比较完整系数、Gauss 场值和由真实记录场导出的梯度；分别按 field/degree/单位加权，不能让大幅值量统治损失。积分权重需是适合误差范数的非负几何度量，不能不加解释地用 signed J 得到“负误差”；这不同于原生装配保留符号的规则。
6. 验证常数/线性/曲边解析场、相同 dof0 不同高阶系数、单位与布局 roundtrip、共享 DOF、一阶特征扰动、Torch 梯度与参考差分。这里保证的是离散表示兼容，不是网络预测绝无失真。

## 4. 参数的适定耦合

建立逐项参数路由表：`name/group/unit/provenance/available_at/normalizer/consumer/supported_range`。

- 场景/控制参数：分组编码后可调制空间输入与 CfC 时间核心。仅从物理作用有依据的路径进入，不把 run ID、文件序号或未来诊断当作场景量。
- 物理系数：优先通过确定性闭合或有单位的局部系数进入对应响应；直接可学习路由必须登记为近似，并验证作用方向/量级。参数既进显式消费者又进网络时声明各自角色，避免物理项重复计入。
- 数值时间：dt、前 dt、格式、事件标志独立处理；不把格式编码当成物理场景身份。
- 静态参数一般不由优化器更新；学习的是参数到响应的映射。未知物理参数反演是另一任务。
- 保留 FiLM/AdaLN 恒等初始化作为可选实现惯例，不再强制参数响应只能整体缩放。检查不相关参数的隔离及相关参数的条件敏感性；不要求所有物理条件的深层 Jacobian 为零。
- 训练数据内恒定或共线的参数显式标注不可辨识。参数扰动测试只证明结构能响应，不证明真实物理泛化；不能用无真值的参数置换样本当作正确监督。

## 5. 时间核心与状态更新 Interface

外层保留场步与既有事件驱动顺序。内部固定 `state/history + spatial features + routed conditions + time + optional memory -> candidate increment + next memory + diagnostics`；外层负责单位、约束、原始历史提交。CfC 为首个新增 Adapter；当前无记忆联合场步是可复用结构/比较候选，后续核心不改数据和物理流程。不为尚无实现的核心建插件框架。

**残差网络为明确约束**：完整原生场绕过有损latent经恒等支路传递，空间主干使用残差块，
最终 `U_next=U_current+ΔU_applied`。网络学本步总增量，不要求先求完整JOREK解再学误差。
所有增量分支（含其偏置）归零时，对已满足约束的状态保持场值不变；这与dt=0时还须
保持历史/记忆/时钟不变是两个测试。零权重初始化本身不保证训练后的no-op，需由结构保证。
步长包装和约束是整步责任，CfC单元保留原版公式。隐藏宽度变化的投影skip不等于完整场恒等
skip；外层场状态始终保留。残差连接不能自动证明累计误差、能量守恒或刚性稳定。

原版 CfC 的库/源码版本、配置、隐藏宽度和 memory 初始化需登记；不能用自写指数门冒称原版。完整物理更新负责零时间 no-op、共享 DOF/BC 与一致历史；原版 cell 不必独自满足物理流恒等。物理增量是 step increment 还是 rate 必须唯一声明，避免外层重复乘 dt；零时间设计不能掩盖物理正步长的刚性失真。

每节点/DOF 的学习记忆显式保存，不能冒充完整 marker 或流体历史。训练用 Torch 逐步传递；不能使用现有 no_grad NumPy reference_solver 训练跨步网络。若源链暂时不可微，可做显式 stop-gradient 的混合训练并报告梯度断点，不宣称端到端闭环可微。

## 6. Teacher forcing → 连续自回归

1. **Warm-up**：以预测起点以前的真实历史初始化学习记忆；不计目标损失，长度待实验，不继承旧30帧。物理历史独立完整恢复。
2. **局部监督**：教师强迫使用同一时间的真实 U 和原始 D_u 作为配套场输入。若用教师 S/D_S，标为独立 source teacher policy；不能把场 TF 比率直接当作源退出比率。
3. **短段自回归**：逐步拉长连续模型推进区间、降低教师替换频率，梯度跨预测步骤传播。未来真实 U/D_u/梯度只作为标签，除非显式训练掩码允许教师输入。与原始轨迹比较仍是轨迹监督，不声称真实下一帧是模型偏离状态的专家一步解。
4. **一致性替换**：场单独训练时一起替换 U/D_u，梯度由替换后 U 重算；学习记忆如何保留/重建须固定。耦合训练不得随机独立混合真实场、预测云、真实反馈而称物理一致。优先使用匹配初始化后的连续 rollout 段；无法恢复一致完整状态时不要在段内执行“教师全状态重置”。
5. **纯自回归验收**：固定一次初态，之后场、云、反馈、shard、历史与时钟全由模型/确定性流程推进，无教师替换；分别报告 field-only/teacher-source 与 coupled/self-source，后者才是 C0。
6. **训练检查点**：已有推理 checkpoint 不是训练续跑协议。新增 optimizer/scheduler、采样器与课程位置、teacher masks/RNG、normalizer、核心版本和截断点状态；TBPTT 可 detach 图但不得清物理状态/附加 JOREK restart。

Teacher forcing 是优化课程，不是累计误差上界；scheduled sampling 不等于 DAgger。只有在模型访问的状态上由专家重新求得目标并聚合数据，才称 DAgger；当前不要求运行这种专家回路。课程长度/概率与损失权重均须配置、记录，依据验证段调节，不用测试集选取。
