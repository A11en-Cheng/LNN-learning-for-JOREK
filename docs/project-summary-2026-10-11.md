# 项目进展与工作收束（截至 2026-10-11）

本文汇总当前实现、已执行实验、近似与未验收事项，供后续 agent 接力。它不是新的 ADR，也不把流程测试、局部数值对照或短程训练升级为物理精度认证。工作树存在大量既有未提交修改；具体实验配置、版本和机器产物以所链接报告为准，不能把不同阶段的结果拼成同一条收敛曲线。

## 1. 目标与当前结论

最终目标是学习 JOREK 的物理状态推进，控制自回归累计误差，并验证相对 JOREK 的计算加速；不是再实现一个完整 JOREK 求解器，也不是仅拟合节点标量。

目前已经具备完整原生场状态、兼容值/梯度、参数特征、残差空间网络、官方 CfC、显式时间记忆和持久源/shard 事件链。两个强 SPI 驱动的 phaseA 已执行无未来真实场回授的有限完整云事件和极小预算训练。但尚未证明长期准确、跨步长可靠、物理守恒或 JOREK 整体加速，不能宣称 C0 已完成。

2026-10-11 的工作重点收束为：**保留源耦合成果，暂停继续扩大耦合训练和 marker 优化，先用真正的纯流体数据验证独立流体推进 head。** 本轮只建立候选入口和无训练测试；新数据由用户另行提供。

需要避免两个误解：

- 当前含源网络并非没有源输入：双源、完整投影历史、电荷闭合及源时钟已经进入空间网络和 CfC。尚未证明的是它学会了正确的源驱动响应，以及能否跨越尚未计算的未来源事件。
- 过去的 `field_only_no_feedback_consumer` 只表示不消费显式源反馈；其 phaseA 标签仍受强源驱动。删除源输入不等于得到纯流体数据。

架构依据为 [roadmap_v2](../roadmap_v2.md) 和 [现行 ADR 索引](adr/README.md)。ADR-0020 管事件/双源/持久状态，0021 管完整残差场步、CfC、参数和课程，0022 管含源联合学习，0023 管显式局部 marker 细分近似。ADR-0001..0017 为历史，不作为新工作的 gate。本轮没有修改 roadmap 或撤销既有 ADR；纯流体 head 是隔离实验入口，不是把原含源主路径静默改成无源主路径。

## 3. 当前流体学习路径

九场顺序为 `psi, Phi, Z_j, omega, rho, T_i, v_par, rho_imp, T_e`。当前主路径输入/输出原生布局均为 `[9,4,1,N]`；四个 degree 全部保留，节点 dof0 只是一种有损观察。`rawD` 是检查点原始流体历史增量，不用相邻保存场相减替代。

已有接口的典型数据流为：

```text
完整 U + rawD + 当前/前步长 + 时间格式 + 显式记忆
    + 同场 cubic 值/RZ 梯度 + 已路由参数
    + [含源模式才有：双源/投影历史/闭合/源时钟]
  → 编码 → 残差节点 stencil → 官方 CfC → 外层记忆时间门控
  → 解码学习速率 → 按本步 dt 积分 → 共享自由度/已支持约束
  → U_next = U + delta_U；更新 rawD、记忆和时钟
```

完整原生场/历史编码包含 36+36 个系数特征及 5 个时间特征。兼容 Gauss 值/梯度与节点聚合另走特征支路，不能把聚合的节点特征称作完整 FEM 装配。物理参数支路当前主要为 `eta × grad(psi)`；SPI 场景编码使用 `n_spi/pellet_density`。其它输运系数、外加驱动和边界参数的完整路由仍需核查。

含源模式的 `JointSourceEncoding` 接收完整 marker 五通道及原始投影 deltas、两个独立质量源通道、Gauss 值/梯度、电荷闭合和时钟，形成 101 维节点输入后编码到 latent。它在 stencil/CfC **之前**加到场特征，不是额外叠加电子容量求解得到的增量。五通道不是固定的“5→9 直接 RHS 矩阵”；九场响应由网络联合学习。冻结容量模式只保留为互斥参考。

实现及依据：[原生联合场步](../report/native-joint-field-step-2026-10-08.md)、[G/P 特征](../report/native-compatible-features-parameters-2026-10-08.md)、[含源联合学习](../report/native-joint-source-learning-2026-10-08.md)。

### 时间与单位的边界

官方 `ncps` CfC 未被改写成 JOREK 的闭式解。当前外层独立适配器使用 `q=dt_JU/tau_JU`，记忆以 `-expm1(-q)` 门控，解码速率按 q 形成场增量。固定有限输入下的 `dt→0+` 一致性及 dt=0 完整 no-op 已测试；这不证明分步组合恒等于一次大步，也不保证剧烈源事件下的正确跨步长响应。

场、原始增量和主要相对指标直接用 JOREK 原生单位；R/Z 几何为米，事件时钟/接口控制为秒，并显式转换 `dt_JU=dt_SI/t_norm`。ADAS 入口使用 SI 电子密度和 eV 温度，再按约定换算率/投影。训练统计缩放是额外数值处理，不能笼统称“所有输入都已用同一种 JOREK 归一化”。详见 [单位说明](jorek-normalization.md) 与 [时间一致性报告](../report/native-field-time-consistency-2026-10-08.md)。

## 4. 已搭建的 shard—云—投影—场反馈

当前不是从未来真实投影插值出源。已有 shard 状态和已可用的场/历史驱动消融、出生、云推进和沉积，再解独立 FEM 投影问题，生成当前事件交给场网络的源对象。独立 shard 密度率不等于 marker 第五通道，不能共用 marker 滤波投影替代。

普通 base 事件保留以下依赖和提交边界；注册 restart 启动先执行零投影的流体/shard 事件，不在启动前采样粒子：

1. 用因果可用场及 rawD 时间采样把持久 marker 云推进到已提交流体时刻，包含出生、电荷演化、辐射、运动和移动前位置沉积；形成完整投影及其原始历史，另形成 shard 密度源。普通事件生成的是已完成窗口的反馈，不是拿未知未来场生成下一段真实源。
2. 双源/历史/闭合进入联合九场场步，得到新场候选。
3. shard 按旧速度移动、旧消融率侵蚀，再在新位置用 **OLD 场**及合法 nonlocal 缓存计算新消融率/rocket 更新；不能偷偷使用新场候选替代 JOREK 的顺序。
4. 候选场、rawD、marker、反馈、shard、时钟与诊断统一返回；失败回滚。新场 Ψ 重建支持域内的磁轴/X 点/边界及后续诊断，不在失败时回退未来真值。

持久状态包括完整 `P_imp`、`V_prev`、身份/槽位寿命、出生时刻、输运历史、前投影及 raw projection deltas、shard 位置/速度/半径/消融率和诊断缓存、CfC memory、流体 rawD、时钟和 RNG。模型检查点恢复不触发 JOREK restart；注册 restart 的零投影启动是另一种显式事件。

已有纯 Ne 的局部 Parks3、rocket6、nonlocal max 分支、PLT+PRB 全荷态辐射与生产出生/密度机制；目标支持域仍有限。检查的是本地 JOREK HEAD `54c675bcc39c33b082c0c35046e28122dc53b3aa` 的源码，不能等同认证日志所述 dirty 生产二进制。历史 rank-lag/aux 生命周期、单 rank 模型 RNG 与生产 PCG32/MPI 差异、物理边界及数值近似仍须登记。

场/CfC 的 Torch 路径可跨步反传；NumPy 源/shard/平衡诊断仍是 stop-gradient。它不阻止前向因果闭环，但会限制用下游误差训练上游物理/源依赖，不能宣称全流程端到端可微。

证据：[持久状态](../report/marker-persistent-state-implementation-2026-10-07.md)、[生产源机制](../report/native-source-production-mechanisms-2026-10-09.md)、[自主完整云冒烟](../report/native-autonomous-smoke-2026-10-09.md)。

### 出生概率表与误差统计

JOREK 的出生候选按叠加总源计算接受概率，不是每个 shard 独立截断后各生一批。当前新方法针对接受后的空间分布构表，饱和关系是 `min(1,sum_j f_j)`，不是先对各 shard 截断再归一化叠加。n=0 路径保留环向核抽象，并使用明确的边缘分布近似。

真实入口目前采用每最小活跃源宽 **64 格**，不是整域 64 格；显式 debug seed 与完整 RNG 恢复已接入。特定概率积分诊断的相对误差为 v400 `4.46e-5`、injInner `3.60e-5`，不能据此给五通道投影承诺相同上界。

8 个物理窗口×8 个 seed 的条件源对照中，全云电离通道新/参考空间相对 L2 均值约为 8.135%/4.417%，参考/参考为 8.137%/4.693%；相关度均值为 0.996431/0.998885。少量中性新生粒子对电离增量贡献较大，位置抽样改变局部原子响应和沉积位置，因此空间差异可以远大于概率表误差。结果支持与参考抽样噪声相近，不证明无系统偏差；尾部仍需监测。这是固定真实场条件的诊断，不能替代自主预测误差统计。

详见 [出生原生修正](../report/native-birth-native-correction-2026-10-10.md)、[电离多窗口复核](../report/native-ionization-window-review-2026-10-10.md)。

## 6. 性能成果与仍存瓶颈

保留了原生参考路径，逐项增加可选优化：重复试算复用、拓扑/邻接复用、批量 cubic 求值、nearby 定位、出生概率表、单元函数缓存及编译 ADAS。不是把整个云交给 GPU 解一个矩阵；持续计算量仍来自粒子子步、场采样、移动后逆定位、OLD 沉积、诊断和源准备。

单元函数缓存保存的是每单元几何/场/反馈的 bicubic 函数系数，约 8.16 MB；不是数 GB 的全空间离散场表。该实验加速采样但不自动加速逆定位，也不消除每个粒子独立电荷/运动历史。原生对缓存 A/B 曾有一个非活跃粒子的末段历史相对差 `3.44e-10`，已记录，不能称所有缓存分支都逐位等价。

最新编译 ADAS 完整事件配对对照：

| 算例 | NumPy ADAS 完整事件均值 | 编译 ADAS 完整事件均值 | 结论 |
|---|---:|---:|---|
| v400 | 5.6659 s | 5.6838 s | 未观察到整步收益，略慢 0.32% |
| injInner | 37.9143 s | 27.5225 s | 耗时减少 27.41%，约 1.38× |

injInner ADAS 查询内部为 11.407→1.728 s，源推进整体为 31.571→21.128 s。对照保持同一场函数缓存，只替换 ADAS provider；末态所有数组及 RNG 指纹一致，不代表缓存与原生采样的差异消失。每臂两个普通物理事件、两次复测，未训练、未测真实大云 backward；不外推首窗、长程或 JOREK 整体加速。

编译后 injInner 源推进仍约占完整事件 76.8%，场网络前向约 0.053 s。优化前剖析中定位/几何和 OLD 沉积也显著耗时；尚未重新剖析编译后的精确内部占比。ThreadPoolExecutor 完整源的 2/4/8 worker 实测反而更慢，仅采样小范围有轻微收益；没有“多线程一定更快”或“搬到 GPU 就会更快”的证据。

当前暂停继续扩大 marker 优化；R/Z↔单元(s,t) 双向加速映射尚不是已验收交付。静态几何可预存，但任意连续位置的 cubic 逆映射仍需近似、确认/修正和跨边界判据。

## 7. 架构问题应如何界定

**以下是基于论文和代码的工程判断，不是已完成的精度实验。**

用户指出的核心风险成立：只给场 head 当前投影，不足以一般性地决定未来整个区间的源驱动；CfC 的显式时间不能补出尚未演化的 shard/云/源事件。把一次场更新改成大 dt，不等于把完整耦合轨迹压缩成了一次可靠推进。

最小反例是 `dU/dt=S(t)`：两个源在起点有相同 `S(0)`，但一个随后增强、另一个保持不变，端点 U 会不同。除非额外输入/记忆足以确定源的未来，否则 `(U,S(0),dt)` 一般不足以给出唯一预测。这里说的是信息闭合，不是要求推理时读取未来真实投影。

场子系统是受驱动的；其输入还包括 rawD、记忆与时间，但是否编码了足够的隐含源状态未获验证。完整模型的闭环状态则还包括 shard、云、电荷、投影历史、诊断缓存、时钟/RNG等；每次重新生成源再更新场，使它成为**分步混合代理模型**。模块分开本身不意味着前向闭环缺失；分步滞后/数值误差、状态完整性、学习误差与梯度截断是不同问题。JOREK 本身也有 OLD 场 shard 更新和错步源事件，不能仅凭分步就宣布架构物理上必然无效。

但若目标是少量调用直接跨越较长物理时间，现有 base 事件逐次推进的实现没有完成这个目标。需要另选并验证：完整增广状态的联合演化、带源事件的多率推进，或完整耦合映射的宏步学习/蒸馏。以上是未来备选，不是本轮已经批准或实现的改造；也不能保证更大网络会自动解决。

LTC 原论文 Eq.(1)、Algorithm 1、Theorems 1–3 讨论的是含外部输入的隐藏状态 ODE、数值子步、条件性有界性和表达能力；不是对任意物理系统的守恒/准确性保证，也不保证训练快速收敛。见 [LTC 原论文](https://cdn.aaai.org/ojs/16936/16936-13-20430-1-2-20210518.pdf)。

CfC 论文从特定神经动力学近似推导时间门控；输入轨迹进入积分，实用模型又引入可训练分支。其较快求值不意味着可以忽略未来驱动变化；标量近似误差界也不是本项目九场、外层时间适配及混合源闭环的误差界。见 [CfC 原论文，学术机构全文](https://research-explorer.ista.ac.at/download/12147/12355/2022_NatureMachineIntelligence_Hasani.pdf)。

因此，当前模型可称“使用 CfC 的分步混合代理”，不能称为整个场—shard—云系统的原生 LTC ODE 或闭式物理解。转纯流体是去掉一个昂贵、多尺度的反馈子系统，以便检验流体学习核心；它不会自动继承物理可靠性，也不意味着 CfC 已被否定。

本轮代码/JOREK 时序补核见 [混合闭环一手代码证据](../report/native-hybrid-closure-code-evidence-2026-10-11.md)。后续纯流体验证还应检查固定驱动下“一次 dt”与“两个 dt/2”的一致性、参考时间细化、固定物理时长误差增长及边界/守恒；零时间 no-op 不能替代这些指标。

## 9. 新数据到位后的工作顺序与指标

以下为待执行安排，不是已有训练资格或预算批准。

1. **核查物理任务和序列。** 从切片场文件/对应源码与配置确认变量、harmonics、网格、完整 degree、rawD、内部时间/步长/格式和单位；确认 SPI/marker 反馈确实未启用，并明确其它外加驱动和物理边界。缺粒子文件不等于源关闭。restart 用于分段/初始化，不替代逐步序列作为监督主体。
2. **构造纯流体数据入口。** 先划定物理序列的 train/val/test，再构造完整因果支撑＋B 步 burn-in＋H 步预测窗口；全部支撑不跨 split/restart，统计只拟合训练支撑。明确关闭 SPI 编码，按新任务补齐流体参数/外加驱动。没有 rawD 等必需初态就拒绝，不补零或读未来场。
3. **确定 burn-in 基线。** 固定预测起点、物理时长、数据和训练预算，比较预先声明的 B；warm-up 保留记忆，截断策略单独记录。过去近初始权重的 B=0 对照不作为最优结论。
4. **冻结训练方案后再运行。** 先无训练前向/反向及恢复冒烟，再批准预算：单步 TF→混合→多步 AR→K 个 base 更新后的稀疏节点监督。噪声只能加入允许的历史观察；预测段不读未来真实 Ψ 或其它场。跳步先指多个实际更新后只在真实节点监督，不冒称一次宏步闭式推进。大步核心需另做一致性/精度实验。
5. **公开预算与吞吐。** epoch 定义为遍历冻结训练窗口清单；报告 batch、梯度累积、B/H、optimizer 更新数、物理预测时长、参数量和 GPU/CPU 分项耗时。对照恒等场及历史速率外推基线；比较其它时间核心时保持数据/空间模块/预算一致。

每个实际场至少记录：归一化逐场 loss及组成、原生单位相对 L2、Pearson 相关度、本步 delta_U/rawD 误差、R/Z 兼容梯度误差和随 rollout 物理时间增长的累计曲线。按四 degree 和方向分项；不能只看总 loss 或大幅值静态场误差。边界、守恒及关系约束另作任务相关诊断，不能由 correlation 代替。

主空间指标在 Gauss 点采用 `w=R*abs(J)*quadrature`：

```text
relative_L2 = sqrt(sum(w*(prediction-truth)^2) / sum(w*truth^2))
Pearson_r   = weighted_covariance(prediction,truth) / (std_w(prediction)*std_w(truth))
```

零参考范数或常量场相关度记为 undefined 并保留原因，不加 epsilon 掩盖；增量和梯度使用各自的参考范数。训练缩放/权重与这些物理相对指标分别保存。纯流体的 shard/marker 投影指标记为不适用，而非零误差；保留耦合任务则仍需要逐五通道投影、独立密度源和身份匹配的 shard 轨迹指标。

验收次序是：数据/接口正确 → 可重复短程学习优于基线 → 固定物理时长 AR 与时间细化/分步一致性 → 长程误差/边界/物理诊断 → 相同精度下与 JOREK 实测比较成本。不能用“有 CfC”“训练 loss 下降”或“GPU 跑满”替代任何一步。
