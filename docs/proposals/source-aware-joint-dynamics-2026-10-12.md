## 0. 一页结论

**不能说“现有代码完全没办法解决这些缺陷”。** 它已经实现了因果 base 闭环，场网络也确实收到源条件。可复用的原生状态、几何、投影、原子数据、shard 公式、事件和指标资产很多。缺的是将可推进源状态纳入学习演化，以及为跨时段预测建立可验证的联合模型；这不是改一个 dt 或增加一个 concat 就能完成的。

我推荐的研究路线是：

1. 保留当前完整 marker/shard 路径作为数值参考，先研究什么云状态足以预测反馈。
2. 保留 shard 作为显式对象和确定 FEM 几何关系；优先验证网格上的完整 Ne 荷态密度 n_0…n_10，通量/额外记忆按证据增补；少量云包保留为对照或回退候选，不先压缩成只有五通道摘要。
3. 将场、shard、云的候选状态通过稀疏局域交换连接，比较联合 LTC 与联合 CfC；已知原子反应和预算关系尽量固定，不让三个 head 各自猜测。
4. 首先学习 JOREK-compatible 的完整 base 事件映射，保持错步和 gather 语义。
5. 如果联合 base 路径成立，再研究连续生成器和多率更新；最后才研究跨多个 base 的宏步蒸馏。

其中第 2 项的状态充分性是最大理论风险，第 4 项的标签/时钟是最大数据风险，第 5 项的刚性与事件是最大时间外推风险。**没有现成 LTC/CfC 定理保证一次调用就能准确跨越 SPI、随机出生和云反馈。**

纯流体 head 仍可用于隔离检验场核心，但不能代替源联合模型验证。此提案优先回应源演化纳入时间核心的研究问题，不自动批准任何训练。

对连续云的当前判断是：**在明确的共同速度、局域有限速率反应及空间解析条件下，有可行性论证和减负机制；尚未证明有限网格与当前 marker 路径等价，也未测得加速。** 下一步应比较相近反馈精度下的完整成本，而不以少了粒子循环作为验收。

## 1. 现有代码：能复用什么，缺什么

### 1.1 重新核查后的判断

现行依据是 [roadmap_v2](../../roadmap_v2.md) 与 [ADR 索引](../adr/README.md)。0018–0023 各管其已登记领域，0001–0017 只作历史。当前主路径的事实是：

- CoupledNativeField 把双源、原始投影历史、闭合量与源时钟编码到空间网络和 CfC 之前。
- TorchRecomputedSourceEvents 生成源、预测场、用 OLD 场更新 shard、刷新诊断并提交；没有要求每步读取未来真实场。
- 完整 runtime 保存 shard、marker、电荷/速度历史、投影历史、场 rawD、记忆、时钟和 RNG。
- NumPy 源/shard 依赖预测场的前向关系存在，但其重算路径没有进入完整反向图。
- CfC 的隐藏状态仍是节点时间记忆；其场 head 并不直接输出可继续演化的 shard/云状态。

这些事实可在 [本轮一手代码审计](../../report/source-aware-joint-dynamics-code-audit-2026-10-12.md) 中按文件行号复核。现有支持域中的有限闭环成功，不等于全配置生产认证或长期物理可靠。

| 问题 | 当前能力 | 为新目标所需的变化 |
|---|---|---|
| 源信息是否进入场网络 | 已进入，不应再称“完全没源输入” | 让可推进源状态进入联合演化，不止消费已生成投影 |
| 持久云/碎片是否存在 | 已存在于 driver/runtime | 编码为明确的学习状态，保留必要历史和对象时刻 |
| 是否前向因果闭环 | 支持域内已有有限完整事件 | 继续验证长期误差，不因分步就判定失败 |
| 是否端到端源—场梯度 | NumPy 源/shard 处截断 | 新源表示、原子查询、投影及实体查询需要可微路径或明确梯度策略 |
| 大 dt 是否包含未来源事件 | 单个场 forward 不执行这些事件 | 联合 base 多步、多率或宏步模型；不能只放大 dt |
| 定位是否被神经网络解决 | 仍有确定几何查询和逆定位 | 引用坐标推进或网格云可减少次数；不保证零成本 |
| 是否保证物理守恒/长期稳定 | 局部公式/测试与有限训练，不是证明 | 结构约束、预算与误差实验分别建立 |

因此，正确表述是：**现有实现不能直接满足“联合跨时段快速推进”的新目标，但它是可扩展的参考和实现基础，不是数学上无解的代码。**

### 1.2 哪些做法不能补上缺口

单独增宽 CfC、只增加 shard 的全局统计、只把 dt 变大、把全部 marker 塞进一个全局向量，都不能保证状态充分或时间闭合。换成 LTC 也不会自动消除粒子定位、源历史与反馈滞后。

这些方法可以作为局部对照，但不应作为已经解决问题的理由。

## 2. 必须先区分两个目标

### 2.1 目标 A：逼近 JOREK 的离散演化

目标是完整事件映射：

$$
Z_{n+1}=\mathcal T^J(Z_n,h_n,\mu,c_n).
$$

这里的 Z 不只是当前场，而包含原始历史、前步长、对象错步时刻、源缓存、gather/residual clock 和学习记忆；c 是合法外部控制，μ 是物理参数。

普通事件先把粒子窗口推进到已提交流体时刻，生成反馈；该反馈用于下一场步；shard 在提交新场之前读取 OLD 场。注册 restart 的零投影启动是不同事件。该映射是有历史和事件相位的离散算法，不能直接等同于无历史的自治 ODE。

**这是推荐的第一目标**：数据直接来自它，现有参考也能执行它，误差来源较易分开。

§3.4 的空间连续云可以先沿用 A 的 base/gather/OLD 场时序，作为源表示的显式近似候选；这不等于已经复刻完整的 JOREK 离散映射。空间连续化也不自动要求把所有对象改成同步连续时间。

### 2.2 目标 B：建立联合连续或混合动力学

另一目标是定义：

$$
\dot Z=F_\theta(Z,\mu,c(t)),\qquad
Z(t^+)=\mathcal J(Z(t^-),e_t)
$$

其中连续演化和出生、出界、源采样、restart 等事件分别处理。

这可以成为统一的 LTC-style 生成器，但必须重新说明物理状态同步、源率/平均反馈关系、数值历史与事件。**不能取消 JOREK 的源滞后，再把原错步序列当作新连续方程的精确标签。**

A 可以为 B 提供校验和有限步蒸馏数据，B 也可能逼近 A；两者是否等价需要时间细化、事件及标签实验，不由网络名称决定。

本文不修改现行事件决策。改变 OLD 场顺序、云表示、随机语义或宏步语义，需要后续用户选择及相应 ADR/roadmap 修订。

## 3. 推荐的联合状态与云表示

### 3.1 原生场与 shard

场仍保留完整九场 cubic 系数、原始流体增量和前步长，不退回节点 dof0。值和 R/Z 梯度从同一系数与几何导出，不能独立生成互不兼容的梯度。

每个 shard 保持身份、材料/组分、位置、速度、剩余尺寸或质量、保存的消融率、所需诊断缓存和对象时刻。其学习记忆另存；不能用潜向量替代必须可审计的物理量。

输入至少需要局域温密、相关场/梯度和合法 nonlocal 诊断。已有 Parks3/rocket6/volume 等公式可保留为已知主项；网络先学有限闭合或修正，而不是重学全部常数和单位。

### 3.2 云需要表达哪些信息

概念上，完整云可以视为带电荷和输运历史的经验分布：

$$
\nu=\sum_m w_m\,\delta_{x_m,V_{{\rm prev},m},\eta_m}\otimes p_m(z).
$$

p_m 是 Ne 的 11 个电荷概率，η 表示必须保留的其它数值历史。该表达只是对已存在 marker 状态的数学记号，**不是声称 JOREK 求解了 Boltzmann 气体动理学方程**。

压缩后需要回答：哪些分布差异会改变后续输运、反应和源反馈？

| 云候选 | 优点 | 不能假定的能力 |
|---|---|---|
| 全 marker/共享实体时间模块 | 对照清楚，可保留身份和历史 | 成本仍随粒子子步增长，不自动加速 |
| 网格上的 11 电荷态密度 n_z | 保留解析尺度内的位置—荷态分布，可批量反应；减少移动定位 | 不自动保留离散速度历史或亚网格相关；见 §3.4 的适用条件 |
| n_z＋电荷分辨通量＋局域记忆 | 物理量和未解析历史分别可观察 | 有限矩仍可能未闭合；记忆维数/长度需实验 |
| 少量加权云包，携带荷态和运动历史 | 保留移动云结构，比固定密度更丰富 | 合并/分裂、查询和出界仍有成本；需证明压缩误差 |
| 只有五通道投影/全局云 latent | 便宜 | 同投影可对应不同后续反应，不能先认定可推进 |

结合后续 CE/marker 核查，优先研究**连续 n_z 的输运—反应模型**，全 marker 留作参考，少量加权云包留作对照。共同速度与局域反应模型下，完整 n_z 可以是直接可推进的物理状态；不先把额外独立通量和记忆设成必需。复现离散历史或诊断出未解析效应时，再增补对应状态，不能无条件宣布任意粗网格 n_z 已充分。

固定网格云和移动云包是互斥的第一阶段研究候选，不建议一开始叠加两套完整模型。网格云更适合减少反复定位；云包更适合保留强非均匀、穿网格和历史相关结构。

### 3.3 一个状态不足的反例

两套云具有相同位置、权重和荷态概率，因此当前 11 电荷密度及五通道矩相同，但 V_prev 方向不同。带方向历史外推的下一运动增量可能不同，下一空间沉积就不同。这个反例针对保留当前 JOREK 离散 pusher 的下一步复现，不能用它否定共同速度连续模型中完整 n_z 的可推进性。

同样，粗单元内的云分别集中在不同温度位置时：

$$
\overline{K(U(x),C(x))\,\mathbf n(x)}
\ne K(\overline U,\overline C)\,\overline {\mathbf n}
$$

一般成立。因此，多电荷态不能替代空间细化或亚网格闭合。

有限矩闭合与记忆的研究基础见 [R6：Levermore](https://doi.org/10.1007/BF02179552)、[R7：Chorin 等](https://math.berkeley.edu/~chorin/CHK02.pdf)。文献不证明本项目的任意有限状态已充分；更详细的假设边界见 [云闭合文献附录](../../report/source-aware-cloud-closure-literature-2026-10-12.md)。

### 3.4 连续非平衡云：优先验证的具体方案

#### 3.4.1 表示改变，不把非平衡改成日冕平衡

建议把大量独立 marker 的云表示换成网格上的 C=(n_0,…,n_10)。n_z 是物理 Ne 原子数密度，不是计算 marker 的数量；它是独立演化状态，不是每步由当前温度重新查出的平衡比例。云可以使用原生网格或经过验证的子网格；其保正表示不必与九场 cubic 系数布局完全相同，但两者的几何交换必须明确。

Hu 原始模型采用随共同流体速度移动的物质包，而不是为每个离子求独立牛顿运动；其 Fig.6 的 CE particle 对照与 CE fluid 总体接近。这支持将“粒子/网格表示”和“平衡/非平衡闭合”分开研究，不证明任意新网格模型已经等价。[R16：Hu 等，§2.1、§4](https://arxiv.org/pdf/2106.12908)

| 数值表示 | 每步重建平衡荷态 | 从上一荷态按有限速率演化 |
|---|---|---|
| 网格场 | 旧 CE 流体闭合 | 本提案的连续非平衡云候选 |
| 移动物质包 | CE_marker 对照分支 | 当前非 CE marker 分支 |

本地源码的对应区别是：CE helper 由 SCD/ACD 率比构造并归一化平衡表；非 CE marker 使用旧 P_imp 与子步 dt 更新，CE_marker 则查表覆盖概率。CE 装配还消费温度导数/平衡电离势，marker 装配另消费投影载荷与历史；见 [CE/marker 一手核查](../../report/jorek-coronal-equilibrium-vs-marker-evidence-2026-10-12.md)。因此，只输入平均电离度及梯度不能自动替代完整荷态；但一个独立演化的平均电荷模型也不自动属于 CE，它需要另行建立闭合。

#### 3.4.2 有条件的理论可行性

以下是在一致物理单位下的工程推导。假设所有荷态随同一个当前速度 v(x,t) 输运，使用同一位置的共同反应系数场 K(x,t)，出生与边界规则也相同：

$$
\dot x_m=v(x_m,t),\qquad
\dot p_m=K(x_m,t)p_m,
\qquad n_z(x,t)=\sum_m w_m p_{m,z}(t)\delta(x-x_m(t)).
$$

对该经验分布作弱形式求导，可得输运—反应关系：

$$
\partial_t n_z+\nabla\cdot(v n_z)
=\sum_{q=0}^{10}K_{zq}(x,t)n_q+B_z.
$$

这给出物质包与欧拉场表示的相容关系，不是对有限网格/有限步长的误差证明。完整解析的 n_z 已包含空间与荷态的相关和反应结果，无须为了保存非平衡电离再逐个保存原子身份；还要满足：

- 实际 marker 的 V_prev 是离散运动历史；若要求复现该格式，须保留相应离散历史或验证换格式的误差。它不等于本来就存在一个必须逐粒子表示的完整速度分布。
- 本地 V_ext 和密度梯度/诊断的依赖须进入定义明确的通量 J_z；不能直接加任意扩散项并称作源码复刻。
- 有限单元内温密与云密度混合产生的反应平均误差仍需空间细化/闭合；§3.3 的相关性风险仍成立。
- 采用平滑平均出生时，随机路径目标已改变；确定模型与路径集合均值的关系仍按 §7.5 验证。

因此具体候选写作：

$$
\partial_t n_z+\nabla\cdot J_z(U,C,\mathrm{history})
=\sum_q K_{zq}(U,C)n_q+B_z(P_{\rm shard},U).
$$

这里 K(U,C) 是 K(Te(U),ne(U,C),μ) 的简写；电子密度的荷态闭合不可因改成云场而丢失。目标 A 应按已配对反馈/历史求值，目标 B 才研究相应同步候选态闭合。给定系数场的弱形式推导不证明非线性闭合在粗网格平均后仍精确。

原子反应使用已核查的 ADAS 主项；输运离散/必要闭合是首要研究工作，不是只多加 11 个网络输入通道。ADAS 官方将杂质流体输运和电子能量源列为其应用之一，但不认证我们的离散方法。[R12：OPEN-ADAS](https://open.adas.ac.uk/adf11)

#### 3.4.3 shard 出生与五通道反馈

对已核验的中性 Ne 出生配置，可将出生原子注入 B_0，其它 B_z 为零。空间律应来自已有生产核和总源接受律：先叠加，再饱和；基准候选采样测度、几何因子、归一化及出生计数/权重另行保留，不以一个任意 Gaussian 替代。总出生率与空间概率是不同对象；计数量化/权重、入域及出域损失必须记账。

连续云减少的是生成独立粒子的工作，不是删除 shard 消融或源演化。shard 仍读取局域场、改变尺寸/速度，并产生出生源。旧消融、OLD 场、nonlocal/rocket、对象时钟继续按目标 A 的声明时序使用。若改为目标 B 的同步物理模型，另立误差及标签协议。

由同一 C 派生 N、M_1、M_2、电离反应能和 PLT+PRB 辐射；从同一空间表示求梯度，不独立预测另一套不兼容导数。经过实际窗口累积/gather 平均及投影后，才成为当前五通道及原始投影 deltas。即使 C 与 U 共用网格，也不能把瞬时矩当窗口反馈，或将原生投影求解/滤波/边界自动删去。

云的 N 不自动替代流体 rho_imp 或独立 shard 密度源。首先保留两者的用途和预算差异；若以后统一总密度表示，需另行说明近似及避免重复注入的规则。本地选定 Ne 消融分支还存在 marker 模式下的 Z_imp=0 placeholder；不能直接用新云平均电荷替换并声称 JOREK 完全等价，具体证据见上述核查报告 B.5。

#### 3.4.4 给时间核心的是联合状态，不是冻结驱动

拟议 Interface 的 complete_state 应包含 U/rawD、shard、C、所选格式必需的云历史、场/云辅助记忆、反馈/原始历史、时钟、配置及所选模式的 RNG。模型续跑保存这些状态；不同云表示的检查点显式互斥，不从五通道反演唯一初始云，也不把模型续跑当注册 restart。

云 Module 提供当前 n_z 及其兼容梯度；几何交换把同一候选 U 的局域值/梯度送入反应、输运和 shard 消融，再把云反馈送入联合时间核心。零维参数按消费者路由，而非重新采用全集 concat。场 decoder 保留完整九场原生残差支路；云更新共享已知反应与出生，不自由预测一套终态后再叠加第二次反应。

核心应联合更新 (U,C,P_shard,H)，在合法内部交换点重算依赖。将起点 C 拼到 CfC 后只推进 U，不足以实现这个方案。共同速度模型可以先不增加独立通量/额外闭合记忆；若对照发现历史或亚网格残差，再有针对性增加。这也不赋予 CfC 任意大步的物理保证。

#### 3.4.5 本阶段的可行性结论

物理层面：在上述假设下，有同类输运—反应关系的构造依据；数值层面：有限网格、不同输运/反应格式、随机出生及投影仍有误差；工程层面：可复用原生几何、ADAS、shard 主项、反馈定义和事件接口。

当前结论限定为**值得优先验证且可能减负**，不是“已与 JOREK 等价/已更快”。保留全 marker 作为参照，先按第 9 节做固定场、无训练的云/反馈与完整成本对照；通过后才接联合学习主路径。

## 4. 几何关系：确定连线，而非让 attention 猜位置

### 4.1 场到实体：原生 gather

在单元 e 的局域坐标 ξ=(s,t)：

$$
\mathcal G_\xi U=
\big[B_e(\xi)U_e,\ J_e(\xi)^{-T}\nabla_\xi B_e(\xi)U_e\big].
$$

第一项是场值，第二项是物理 R/Z 导数。shard/cloud 接收这些量及自身状态，再预测变化。局域场值的求值关系保持确定；学习的是响应、闭合和未解析误差。

对 cloud 的网格表示，可以预计算固定求值点的 basis/Jacobian；每步只更新场系数及必要流体值。对移动 shard/云包，局域查询仍随位置变化，但实体数远少于全 marker 的假设必须实测。

### 4.2 云到场：scatter、投影和消费者分开

未滤波的示意沉积载荷为：

$$
b=\sum_m B_e(\xi_m)^T w_m q_m,\qquad
A_{\rm proj}S=b.
$$

这里 q_m 表示某一物理通道的贡献；时间因子、R/环向几何和归一化按具体通道定义。上述公式不是固定五通道到九方程的 RHS 映射。

gather 与未滤波 scatter 可以建立测试空间中的配对关系，但解投影矩阵、滤波、轴/外边界约束及场方程消费是另外的算子。**不能只使用转置就宣称整个流程守恒。**

已知几何连接决定信息在哪里交换；网络在这些连接上学习响应。全局 attention 只可作为额外假设，不替代 cubic 求值。FEM 的有符号基函数权重也不能未经验证改成 softmax 的正归一化权重。

对象/关系显式编码可参考 [R5：Deep Sets](https://papers.nips.cc/paper/2017/file/f22e4747da1aa27e363d86d40ff442fe-Paper.pdf)。shard 的顺序不能改变场响应；实体输出应随实体重排相应重排。该要求不意味着采用全局 GNN；本提案优先保留现有场 stencil，用确定 gather/scatter 做稀疏交换，未重启已撤销的 GNN/谱分支。

### 4.3 移动实体的引用坐标推进

固定网格内若 x=X_e(ξ)，则：

$$
\dot\xi=J_e(\xi)^{-1}\dot x.
$$

这是链式法则的工程推导。它允许保存 cell/s/t，并在单元内部直接推进；跨边事件再用邻接关系转换，减少每次完整逆定位。

代价与限制：

- 仍需计算局部 Jacobian，且跨边、外边界退出与退化几何需要处理。
- 大步可能跨越多个单元；不能只检查末态后丢掉途中场变化。
- 改变了数值运动格式，需要与现有 R/Z 移动后反解作单独误差对照。
- 离散单元编号切换不是普通光滑算子；局部场/坐标可微不等于事件自动可微。

网格云能消除大部分逐粒子移动定位，但 shard 定位、活动域管理和通量跨单元仍有成本。活动域只能由已知状态、出生支持和合法可达范围决定，不能提前读取真实未来 marker 范围。

### 4.4 nonlocal 不能被“只看局域”删除

nonlocal 消融诊断和场的全局响应有明确物理含义。推荐保留原生局域 gather，并另传磁通壳统计/合法诊断；局域交换不能擅自改成“所有物理只由近邻决定”。

当前 H=1、n=0 先做二维支持域；环向源核、离散平面与 n=0 归约仍需保留声明，不能把轴对称场等同于任意源核都没有环向结构。

## 5. 让物理关系内禀一致

### 5.1 shard 消融与云出生共享同一物质账

建议预测或计算一个明确的消融原子率 a_i≥0；由它共同决定 shard 质量减少和出生注入。来源、材料、体积和边界损失进入预算。

但 JOREK-compatible 的出生空间律必须单独保留：总源接受概率的饱和发生在叠加之后，不能换成各 shard 单独截断再求和。出生的计数/权重与独立密度核也不是同一个离散对象。

平均云注入若取代随机 marker，需要明确这是改变随机表示的近似；不能仅凭两者总质量相同认定空间反馈等价。

### 5.2 电离/复合采用共享反应转移

在一个固定求值点，建议保留真实 ADAS 系数构成 11×11 反应生成矩阵 K：

$$
\dot{\mathbf n}=K(U,C,\mu)\mathbf n,\qquad
K_{ij}\ge0\ (i\ne j),\quad \mathbf 1^TK=0.
$$

这里约定列向量和列和为零；实际 SCD/ACD 荷态索引、端点、表范围和单位仍按源码。K 不把出生和空间输运伪装为电离。

对被冻结的合法 K，矩阵指数更新保持非负与原子数；隐式 Euler

$$
\mathbf n^{+}=(I-\delta K)^{-1}\mathbf n
$$

也具有相应非负/守恒结构，但只有一阶时间精度。上述是有限生成矩阵的数学性质，不是现有 JOREK 荷态算法的精确复刻。

电子密度、温度和闭合随着联合状态变化时，K 也变化；需要重新求值、迭代或误差控制，不能用一次冻结就承诺任意 dt。可批量求小三对角系统；它与逐粒子求完整 MHD 矩阵不是一回事。

保结构反应算法可参考 [R10：Kopecz–Meister](https://arxiv.org/abs/1703.05052)，但其中部分正性条件涉及正初值/分母，纯中性 newborn 有零荷态分量，不能直接套用。ADAS 各类系数意义见 [R12：OPEN-ADAS](https://open.adas.ac.uk/adf11)。

### 5.3 电离能、辐射与电荷矩由同一云状态生成

示意物理电荷矩为：

$$
N=\sum_z n_z,\quad M_1=\sum_z z n_z,\quad M_2=\sum_z z^2n_z.
$$

电离功率由荷态**反应项**与累计电离势共同计算；不能从整个 n_z 时间导数生成，否则输运和出生也可能被计为电离。辐射由同一 n_z 和 PLT/PRB 生成，保留完全剥离态的对应 PRB。

这些量还需要正确的窗口累积、gather-time 平均、FEM 投影与 JU 转换，才能变成现有五通道反馈。N 仍不替代独立 shard 密度注入。

这样，网络不再独立猜测“电荷怎样变”“能量损失多少”“投影是多少”。可以学习缺失闭合，但已知关系共享中间变量。

### 5.4 输运与场约束

网格云可以使用内部成对通量：

$$
V_a n_{z,a}^{+}
=V_a n_{z,a}
-\delta\sum_b F_{z,a\to b}
+\delta V_a R_{z,a}
+\Delta B_{z,a}.
$$

这里 R 是荷态反应率，ΔB 是本步出生原子数，F 是面上原子通量率。F 使用相同面和相反符号记入相邻单元，内部交换在总量中抵消。开放边界损失另记，不假装封闭守恒；非负还需要合法重建/限制器及相应时间条件，不能由成对性自动推出。

物理体积应含适用的 2πR/Jacobian；高阶 FEM 系数有符号，不应直接把所有 cubic 系数 softplus 成正数。非负约束施加于所选物理密度表示或求值点，场变量/梯度保持原生定义。

场仍是完整联合残差预测。预算结构能约束源，但不会自动使学习出的九场解满足完整 MHD 方程。

## 6. 时间核心：推荐如何比较 LTC 与 CfC

### 6.1 文献能保证什么

[R1：LTC 原论文](https://cdn.aaai.org/ojs/16936/16936-13-20430-1-2-20210518.pdf) 的 Eq.(1)、Algorithm 1、Theorems 1–3 给出特定隐藏动力学、数值求值和条件性有界/表达能力结论。它不保证任意训练都会收敛，也不保证解码物理场满足守恒。

[R2：CfC 原论文](https://research-explorer.ista.ac.at/download/12147/12355/2022_NatureMachineIntelligence_Hasani.pdf) 的标量近似定理有单元/输入假设；实际门控模型还经过可训练结构修改。快速神经求值不能自动决定未知的未来驱动，误差界不能直接覆盖本项目联合模型。

因此，**核心名称是架构选择，不是验收证据。**

### 6.2 联合 LTC：理论参照方案

建议将场、shard、云分别编码为 H_U、H_P、H_C。下面是待研究的 LTC-style 联合隐藏动力学：

$$
\dot h_a=-\lambda_a h_a+
\sum_b g_{ab}(\mathcal C_{ab}(Z),h_a)(A_{ab}-h_a).
$$

λ>0，g≥0；连接信息 C_ab 来自当前候选状态的原生 gather、出生和沉积/闭合。A 是受控的反转值参数，不是任意无界的解码输出。若想证明隐藏状态/时间常数的界，还需分别限定 g 和 A、初态以及离散算法，不能只在函数名中加 LTC。

关键设计原则：

- 每个内部求值点用候选联合 U/P/C 重新计算交换，不冻结整个区间的起点投影。
- 物理位置/质量/云与隐藏记忆分别存储；隐藏状态不要求逐个对应某个 marker。
- shard/反应的已知主项和学习闭合共同决定物理变化；梯度沿这些依赖传播。
- decoder 保留 U 的恒等残差支路；质量和反应转移走受约束表示。

这属于物理主项＋学习闭合的混合建模建议，可参考 [R4：UDE](https://arxiv.org/abs/2001.04385)。这里不是要求移植完整 JOREK 九场方程，也不保证新 LTC 公式已有现成理论证明。

以网格云候选为例，目标 B 的物理状态关系可示意为：

$$
\begin{aligned}
\dot U &= D_{\theta,U}(U,H_U,H_P,H_C,\mathcal S(C,P,U),\mu),\\
\dot P &= F_{P}^{\rm known}(P,\mathcal G_P U,\mathcal N(U),\mu)
+R_{\theta,P},\\
\dot C &= \mathcal L_{\theta}(U,C,\mathrm{history})
+\mathcal K(U,C)C+\mathcal B(P,U).
\end{aligned}
$$

P 在这里表示 shard 物理状态，而不是电荷概率；C 是云表示。𝒢 是局域求值，𝒩 是合法 nonlocal 诊断，𝒮 是共享反馈，𝒦 只作用于对应的荷态物理块，𝓑 来自同一个消融物质账。辅助记忆由上面的时间核心处理；𝓛 负责输运/其闭合，不重复预测反应或出生。首轮可将 shard 修正 R 置零，只学习联合场响应与必要云闭合。

H 是辅助记忆，U/P/C 是可审计的主状态。不能让一个 decoder 自由输出云终态，又无协议地叠加第二次反应更新。以上关系是拟议连续模型的依赖图，不是当前 JOREK base 时序的替换公式；目标 A 仍按离散事件使用这些共享关系。它说明“神经元看到关系”应通过反复求值的依赖连接和共享物理变量实现，而不是靠潜向量自己猜出全部约束。

优点是联合依赖在生成器中清楚；缺点是仍需求解隐藏/物理动力学，刚性和重复求值可能抵消性能收益。

### 6.3 联合 CfC：工程候选方案

先保留官方 CfC 的门控实现，改变联合输入、记忆分组和输出契约。比较两种用途：

1. 在较小的内部区间推进联合潜状态，配合原子反应、物理源关系和共享解码。
2. 在充分监督后直接学习完整事件或宏区间映射，但输出必须可继续演化的联合状态。

不能把“字段增加到 CfC 输入”称作已经得到闭式耦合解。起点参数计算出的门控对整个区间只是学习近似；如果端点预测依赖中间反馈，可以采用可控内部更新或预测—校正，并验证收敛。

现有外层记忆门控/速率积分已经解决了局部 dt→0 问题，可作为比较资产；不应在同一次实验同时改官方 cell、外层积分、云表示和损失，否则无法判断收益来自哪里。

### 6.4 比较时固定什么

固定物理状态表示、空间主干、几何、参数、训练支撑、预测时长和监督对象，比较联合 LTC、联合 CfC、无记忆残差速率基线；必要时再加入普通学习生成器作为诊断。

参数量和内部求值次数分别记录；同参数量不等于同计算预算。非均匀时间的生成器学习可参考 [R3：Neural ODE](https://papers.nips.cc/paper_files/paper/2018/file/69386f6bb1dfed68692a24c8686939b9-Paper.pdf) 与 [R11：时间步约束学习](https://arxiv.org/abs/1808.02578)，但不能由这些参考宣布本模型稳定。

### 6.5 时间与参数的量纲约定

现有入口不是“所有东西都已无量纲”：原生场/反馈采用声明的 JOREK 归一化，R/Z 几何采用米，事件时钟常用 SI 秒，ADAS 求值还有温密/系数转换。新的联合模型应延续显式单位路由：dt_JU=dt_SI/t_norm；时间门控使用无量纲 dt_JU/τ_JU；速率必须声明是每 SI 秒、每 JU 时间，还是每网络参考时间，不能直接混加。

训练支撑统计缩放是另一层操作，不取代物理单位。原子率与功率先按物理定义转换，再按训练统计编码；gather 平均反馈、累计能量和本步增量分别存储，不能二次乘 dt。τ 是可声明的网络时间尺度，不自动等于阿尔芬时间，也不因可学习就成为物理积分误差控制。

零维参数按消费者分组进入 shard 主项、原子/闭合、输运和场分支；边界/事件参数进入对应规则。参数只有在数据支撑中变化过，才能评价其条件化泛化；当前未变化的参数不能靠扩大编码器“学会”响应。

## 7. 多率、宏步与理论边界

### 7.1 先分清三种“跳步”

| 类型 | 实际执行 | 能否称为少调用加速 |
|---|---|---|
| 稀疏监督 | 内部 K 次完整 base 更新，只在真实节点监督 | 不能；只是少算标签损失 |
| 多率联合推进 | 反应/输运有内部微步，场/shard 在已验证交换点更新 | 可能；需要完整成本与耦合误差实验 |
| 直接宏步模型 | 一次或少数调用预测完整联合终态及续跑所需状态 | 可以作为目标，但尚未实现/验证 |

推荐的多率设计按物理时长而不是“记录数量”组织。原子反应可用保结构小系统更新；输运受可达范围与时间精度控制；场/消融反馈不能在长区间内一直冻结而不计误差。出生、消融耗尽、出界和注册事件作为显式跳变/重置，不能全交给光滑门控抹平。混合连续/跳变的建模背景见 [R13：Neural Jump SDE](https://arxiv.org/abs/1905.10403)；它不是本项目出生算法的直接实现。

### 7.2 宏步输出必须能续跑

对于保持 JOREK base 语义的宏步 H=Σh_k，终态不只有 U_end：

- 必须保留终端 shard/云、事件时钟、最后投影与其原始历史。
- rawD 应对应终端最后一个 base 更新所需的历史，不能用 U_end−U_start 替代。
- 前 dt 应是终端真实 base dt，不是宏区间 H。
- 最后 gather 平均反馈与整个宏区间累计源不是同一个对象；两者若都需要，应分别输出。
- 诊断缓存和模式/配置仍有来源时刻；不能把预测终态套进旧缓存。

这些是直接宏步比“输出下一场”困难得多的原因。可以设计宏步 decoder 返回倒数节点信息或完整终端历史，但它本身需要监督/蒸馏证据，当前方案未确定。

### 7.3 时间一致性不是无条件半群

自治、确定、充分状态的连续流满足组合关系；非自治驱动应比较相同控制轨迹上的两参数演化算子。随机系统应明确路径耦合或比较转移分布，单纯相同 seed 不保证不同步长使用相同随机事件。

JOREK 离散 rawD、前 dt 和窗口平均量依赖步分割，一次 H 和两次 H/2 的这些历史数组本就不必相同。因此应：

1. 比较一致物理时刻的可观察量和误差；
2. 对 A 类宏步比较相同 base 控制序列的串行合成与直接预测；
3. 对 B 类连续模型做时间细化和合法事件组合；
4. 另验终端历史能否正确继续下一步。

半群约束学习可参考 [R14：Deep-OSG](https://arxiv.org/abs/2302.03358)，其研究对象为自治演化。不能把它的属性直接要求到错步平均量和不同随机路径上，也不能仅靠一致性 loss 排除恒等、不演化的退化模型。

### 7.4 一个可用但有限的误差推理

对指定有限区间、同控制下的确定性生成器，假设 F 为 L-Lipschitz，学习/闭合误差有界为 ε，则常见比较估计为：

$$
\|e(t)\|\le e^{Lt}\|e(0)\|+
\frac{\epsilon}{L}(e^{Lt}-1)\quad (L>0).
$$

这是在上述假设下由微分不等式得到的工程推导；不宣称实际 MHD 全域满足统一 L/ε。刚性、低密度敏感性、事件跳变和分布变化均可能破坏简单估计。

含义是：小单步误差也可能累积，隐藏状态有界也不控制场误差。需要把表示、反应、输运、投影、学习场、时间和事件误差分别测量，不能只看训练 loss。

### 7.5 随机路径与平均云必须选择目标

预测固定 RNG 路径、条件均值、条件分布是三个任务。一般：

$$
\mathbb E[\Phi(X,B)\mid Z]\ne
\Phi(\mathbb E[X\mid Z],\mathbb E[B\mid Z]).
$$

所以确定平均出生＋平均云并不自动等价于多条 marker 轨迹的平均场。应保留参考/参考噪声实验；选择均值模型后不能承诺某条生产随机轨迹逐粒子一致。

该目标选择应在训练和宏步实验之前完成；研究压缩时可以先测条件均值偏差和尾部，再决定是否需要随机 latent。

## 8. 可行性：成本、梯度和数据

### 8.1 计算规模与内存

全 marker 的主要规模近似为粒子访问数：

$$
O\!\left(\sum_k N_{{\rm live},k}\,
[\text{定位}+\text{采样}+\text{反应}+\text{沉积}]\right).
$$

网格云的规模转为活动单元/子单元数、通道数和 stencil 边：

$$
O(N_c\,11\,K_{\rm micro}+E_c\,d+N_c\,d^2L_{\rm net}).
$$

这里只是粗略成本分解；非线性迭代、投影、诊断和空域占用另计。若云遍布全域、需要很细子网格或长内部微步，收益可能消失，不能承诺几个数量级。

**假想容量算例，不是实测**：20,000 个活动存储点，每点 11 密度＋22 个二维电荷通量＋16 记忆通道，FP64 单份状态约 7.84 MB。每个点细分为 16 个存储点则约 125.44 MB。另有场、网络激活、梯度、optimizer、投影与诊断；长 BPTT 不能把单份状态内存当训练峰值。CPU 内存充足也不代表 GPU 显存充足。

参数由共享局域模块决定，不应为每个 marker 独立分配一套权重。隐藏宽度/记忆维数应从候选状态实验选择，当前没有“应该多少参数”的证据。

连续云具体减少/转移的工作是：

| 现有 marker 路径 | 连续云候选 | 仍需计入的成本 |
|---|---|---|
| 接受/拒绝并分配独立粒子 | 计算连续出生分布，直接注入中性荷态 | shard 核叠加、饱和/归一化、几何与预算 |
| 每粒子移动、逆定位和场采样 | 活动网格统一输运；固定点复用 basis/Jacobian | 通量/限制器、活动域、必要微步；shard 仍需定位 |
| 每粒子反应与辐射 | 网格点批量 11 荷态反应/辐射 | 温密求值、ADAS 查询及刚性时间精度 |
| 粒子 scatter 沉积 | 对连续矩/能量率作网格求积 | 原生投影、滤波、边界及 gather 历史 |

只存 11 个 n_z 时，上述假想 20,000 存储点的 FP64 单份云状态约 1.76 MB；7.84 MB 算例中的通量/记忆是扩展候选，不是已经选定的最低配置。两者都不是训练显存或生产峰值预测。

收益取决于粒子访问数是否被更少的网格工作替代。细网格、长微步或大活动域可能抵消收益；CPU 常驻缓存/GPU 批处理是实施选项，不保证自动加速。必须在相同物理时长、相近五通道精度下比较整链 wall time，不只比较单个反应内核或 GPU 利用率。

现有 [编译 ADAS 对照](../../report/native-compiled-atomic-optimization-2026-10-11.md) 中 injInner 普通事件约 27.52 s，源推进约 21.13 s，场网络前向约 0.053 s。**仅对这个代理事件的算术估计**：若源耗时理想归零，其它阶段不变，整步上限约 4.3×；源减为 1/4 时约 2.36×。这不是新模型预计速度，也不是 JOREK 基线。

连续云不会把上述源成本自动归零；投影、诊断、shard 和事件提交仍在。没有新 benchmark，不能由该代理事件推算连续云的实际加速倍数。

### 8.2 可微几何和投影

固定单元内，原生求值对 U 和局域坐标可微；离散跨单元、出生槽位、耗尽和出界不自动可微。第一阶段可固定事件分支做局部梯度校验；后续选择分段可微/事件敏感度策略。不能悄悄把全部事件 stop-gradient 后仍声称端到端梯度。

如果 A_proj 为固定线性算子，则：

$$
\frac{\partial\mathcal L}{\partial b}
=A_{\rm proj}^{-T}\frac{\partial\mathcal L}{\partial S}.
$$

这是固定线性解的反向关系，可复用因子；若矩阵/滤波随 ψ 或其它学习状态变化，还需相应矩阵导数。不能用固定矩阵公式掩盖遗漏项，也不能直接沿用 SciPy detach 作为可微求解。

ADAS 表可继续常驻内存。若要对温密求导，分段插值的导数、端点截断和表格式需单独实现/验证；现有编译 provider 的位一致前向不等于已有反向。

### 8.3 数据是否足够

两个 phaseA 提供强源、不同空间位置和步长的有价值案例，但不是联合闭合可辨识性的证明，也不能支撑所有参数/分布族外推。

需要清单：

| 数据 | 用途 | 缺失时的处理 |
|---|---|---|
| 完整 U/rawD、几何、内部时间与有效参数 | 场和历史监督 | 不补零，不用舍入端点差冒充 rawD |
| shard 身份、位置/速度/尺寸/消融率/缓存 | 显式对象监督 | 标记时间/字段缺口，不能只用总质量替代 |
| 完整或合格稀疏 marker 初态、P_imp/V_prev/时钟 | 初始化及云编码 | 不能由五通道反演唯一完整云 |
| 因果对齐五通道/原始历史、独立密度依据 | 源反馈验证 | 不用下一帧投影当本步输入 |
| 云的密度/通量/历史目标 | 选择压缩表示和闭合 | 可用参考 replay 生成模型标签，但须区别真实 JOREK 标签 |
| 多条件/多 RNG 的固定场诊断 | 区分闭合偏差与抽样波动 | 缺证据则不声称均值等价或统计误差 |

切片序列仍是主要监督主体；restart 只服务合法初始化、分段和特定事件。稀疏 marker 数据限制哪些云量有真值，不意味着所有后续模拟量都能改名为真实监督。

### 8.4 闭合是否可识别

不能仅靠场 loss 决定云表示：不同云可能产生相近短程场，却有不同未来反应。应比较压缩条件下同场/同 shard 的下一步分散程度，检查残差时间相关与增加历史后的变化。

Mori–Zwanzig 启发给压缩状态增加记忆，数据驱动估计可参考 [R8：Lin 等](https://arxiv.org/abs/2101.05873)。这些文献有各自投影和采样条件，不意味着一个有限 CfC memory 能恢复全部丢失的信息。

## 9. 建议路线与停止条件

以下是研究里程碑，不是自动执行授权；不预设未获批准的训练预算或精度数字。

| 阶段 | 交付 | 继续依据 | 不通过时 |
|---|---|---|---|
| R0 目标冻结 | A/B、路径/均值/分布、允许近似、预算对象和时间含义 | 用户明确取舍 | 不改核心 |
| R1 状态充分性 | 优先完整连续 n_z 的编码/重建与固定场推进；marker 为参照，必要时比较矩＋记忆或云包 | 下一反馈偏差和条件分散可控制 | 增加状态/分辨率，不用大网络掩盖信息缺失 |
| R2 空间交换 | 原生 gather、出生注入、云 scatter/投影及单位/预算对照 | 源位置、梯度、重叠饱和与边界正确 | 修几何/源定义，不训练补偿错误单位 |
| R3 联合 base 原型 | 可恢复联合状态；LTC/CfC 可比较；无未来输入 | 前向、跨步梯度、续跑、时间配对通过 | 区分事件/梯度断点与学习问题 |
| R4 有界课程学习 | 固定 split、burn-in、单步→多步 AR、逐对象指标 | 固定时长优于预先声明基线 | 查分布/闭合/核心，不无限追加预算 |
| R5 多率/连续研究 | 与 A 参照的误差、源积分和事件预算；明确 B 的新语义 | 时间细化和完整成本有收益 | 保留 base 学习，不声称直接跳步 |
| R6 宏步蒸馏 | 完整联合终态＋终端历史，可继续下一 base | 同控制序列、固定物理时长与长程验证 | 回退已验证步长/显式事件 |
| R7 JOREK 对照 | 同物理任务、同精度和工作单元的总 wall/资源 | 实际精度—成本收益 | 不以 GPU 利用率或网络前向代替加速 |

建议第一轮仅批准 R0–R2 的设计/无训练实验，再决定云表示和核心。若源状态尚未确定，直接重写 CfC 很可能将问题藏进更多参数。

### 连续云的首轮无训练验证顺序

以下仅为任务安排，不是本轮已执行结果：

1. **合法初始化与重建**：从已认证 marker 初态或独立荷态真值编码 n_z，校验各荷态原子数、空间矩和反馈重建；不能由五通道补出唯一云。登记网格/子网格、单位、初态与误差。
2. **固定场的条件物理对照**：保持同一完整 U/rawD、有效参数、物理时长、出生与边界，比较参考 marker 和连续云的反应/输运。可先隔离无输运反应，再加入输运与出生；采用同一接受律的合法路径或明确的多 RNG 统计目标。读取真实场只服务条件诊断，不认证自主 rollout，也不授权未来真实场进入 AR 训练。
3. **五通道与预算**：报告逐荷态误差、N/M_1/M_2、五通道空间 relL2/Pearson、积分/热点和原始投影历史；同时记录物质出生/逸出与电离能/辐射账，区分源率和 gather 平均。零参考范数按 §10.3 处理，不把平均一致称为统计等价。
4. **相近精度下的整链成本**：预先声明可接受的反馈误差，做网格/时间细化并记录总 wall、各阶段、冷启动/稳态、CPU/GPU/传输和内存峰值；固定场对照不包含学习 backward，因此不冒充训练加速证据。失败或需极细网格时，回到已解析误差，保留 marker/云包参照。
5. **再接联合 base 路径**：前四项通过后，才将 C 纳入联合状态，核查预测场回授、跨步梯度、续跑/回滚、边界和 gather 时序；之后另获训练预算。无需先训练网络来补偿错误出生核、单位或输运。

继续条件应是“反馈误差与预算可接受，并有完整成本证据”，不能仅为“11 个通道已接上”或“少了粒子循环”。具体阈值/预算仍待选择，本提案不自动采用概率表 1e−5 作为整体反馈目标。

### 可复用与新增的 module seam

外部 Interface 可概括为：

    advance_joint(complete_state, controls, geometry, parameters)
        → complete_next_state, physical_budgets, diagnostics

这是拟议 Interface，不是新增代码。内部 seam 至少隔开：

- 原生 GeometryExchange：gather、Jacobian、空间沉积及模式；
- CloudRepresentation：编码/重建、必需历史、误差与支持域；
- ShardPhysics/AtomicReaction：已知主项与可学习闭合；
- JointTemporalDynamics：LTC/CfC 等互斥 Adapter；
- FeedbackObservation：独立密度与五通道、gather 平均及历史；
- EventCommit：时钟、事件、恢复、失败回滚。

不能向调用方暴露一串需要自行按顺序更新的候选数组，让它负责补齐一致性。现有 driver/状态/校验和多数几何资产可复用；云表示、联合学习状态、完整源梯度和宏步历史属于新增研究。

## 10. 训练与验收：避免只看 loss

### 10.1 训练语义

先按物理序列隔离 train/val/test，再在各自完整支撑内构造 burn-in＋预测窗口；不跨 restart 或 split，缩放只拟合训练支撑。

burn-in 在固定预测起点和物理时长下比较，保留必要状态/记忆；截断计算图不清物理历史。teacher forcing 必须是相互配对的场/源/shard/cloud bundle，不能只替换 U 而留不一致的云缓存。

监督真值只用于 loss 和显式教师干预；AR 不读未来真实场/投影。已声明、可用的外部控制轨迹与未来监督标签不是同一对象。

建议课程顺序：条件源/表示诊断 → 单个完整联合 base → 短程联合 AR → 固定物理时长长程 AR → 多率/宏步对照。前两项不能替代最后的自主闭环验证。

### 10.2 loss 的建议组成

监督项可写成：

$$
\mathcal L=
\mathcal L_U+\mathcal L_{\Delta U,\nabla U}
+\mathcal L_P+\mathcal L_C+\mathcal L_{S_5}
+\mathcal L_{\rm history}.
$$

各项归一化、权重、标签可用性分别公开；缺少云标签不伪造为零误差。预算优先由结构保证，再做诊断。额外物理/一致性损失只作为待批准选项，不能把当前不支持的全 MHD residual 自动加入训练，或违反现行路线。

保结构学习可参考 [R9：Schotthöfer 等](https://proceedings.mlr.press/v162/schotthofer22a.html)；它针对特定熵闭合，不能保证任意神经通量或本项目九场更新保正/稳定。

### 10.3 必报指标

| 对象 | 主要指标 | 防止误判的补充 |
|---|---|---|
| 每个原生场 | 逐场 loss、相对 L2、Pearson、各 degree、R/Z 梯度 | 场增量/rawD误差；静态大幅值场不能掩盖动力学 |
| 五通道投影 | 各通道空间误差/相关度、积分、峰值/热点位置 | 分开功率率与电荷矩，记录实际 gather |
| 独立密度源 | 总量、空间误差、支撑/边界 | 不以 c5 指标代替 |
| shard | 身份匹配的位置/速度/尺寸/消融率误差 | 轨迹误差及耗尽事件，不只总质量 |
| 云 | 电荷分布、空间质量、通量/历史、反馈重建 | 网格云不强求逐 marker 身份；选择均值则另报方差 |
| 时间/历史 | 固定时长误差增长、合法拆步/细化、恢复和下一步误差 | 不比较本就不同定义的宏区间 rawD |
| 物理预算 | 原子、注入/逸出、反应能与辐射账、边界关系 | 不是封闭系统时不要求无条件总能量恒定 |
| 性能 | 完整窗口 forward/backward、CPU/GPU/传输/投影/诊断 | 标签生成、初始化、失败重试和长期成本另列 |

主要相对误差直接在相应原生单位中计算：

$$
{\rm relL2}=\sqrt{
\frac{\sum w\,(\hat y-y)^2}{\sum w\,y^2}}.
$$

场/投影的 Gauss 权重按适用的 R|J|quadrature；增量、梯度和各通道各用自己的分母。零参考范数/常量相关度记 undefined，不能加 epsilon 制造看似良好的指标。

随机源需要参考/参考和新/参考配对统计，但相近均值不证明统计等价。现有 [电离多窗口诊断](../../report/native-ionization-window-review-2026-10-10.md) 是固定真实场条件；不能用它认证新联合 AR 的误差，也不能把概率表 1e−5 误差当成全云投影或场预测目标。

### 10.4 最有价值的因果测试

1. 移动 shard 而保持总质量相同，出生支撑和场响应是否相应移动？
2. 同投影、不同荷态/速度历史的两套云，模型是否区分下一反馈？
3. 修改局域温密或梯度，消融/反应是否按声明主项和限制变化？
4. shard 顺序重排、重叠饱和、纯中性 newborn、低密度敏感区是否正确？
5. 用预测 ψ/nonlocal 诊断后是否继续稳定，不回退未来真值？
6. 同控制下串行 base 与宏步终态是否能继续预测同一后续区间？
7. 无监督内部节点是否只是网络自行推进，而非未来标签插值？

这些测试证明结构依赖和边界契约；只有充分真实/参考误差与长程实验才能证明预测效果。

## 11. 风险、取舍与建议选择

| 风险 | 严重度判断 | 应对 |
|---|---|---|
| 压缩云不足以确定未来 | 高，首要风险 | 对比 n_z、矩＋记忆与云包；条件分散/历史残差测试 |
| 把源平均标签当瞬时值 | 高 | 明确 A/B、对象时刻、gather累积与终端历史 |
| 平均云改变随机反馈目标 | 高 | 先选路径/均值/分布；多 RNG 和非线性偏差对照 |
| LTC/CfC 大步失准或刚性高 | 高 | 已知反应保结构；固定时长、内部求值、事件与细化实验 |
| 学习隐藏状态有界但物理场漂移 | 高 | 独立测量场预算/误差；不迁移隐藏状态定理 |
| 离散几何/事件梯度错误 | 中高 | 局部梯度 oracle、事件策略和支持域守卫 |
| 两个 phaseA 支撑不足 | 高于普通拟合风险 | 来源/单位审核，补有目标的扰动与状态支撑，不宣称泛化 |
| 新模型并不更快 | 中高 | 完整成本及基于误差的性能比较，不仅减少 marker 数 |
| 改动太多无法归因 | 可控制 | 状态表示、核心、时间方案分阶段对照 |

我的建议是：

- **研究对象**：对场有效的持久云演化及反馈，而非强求生产 RNG 的逐 marker 身份重现；这仍需用户选择。
- **参考路线**：先 A，保持 JOREK 事件语义；B 和宏步分别作为后续新假设。
- **候选云**：优先独立推进的 11 荷态连续云；通量/额外记忆按历史和未解析残差增补；全 marker 为参照，少量云包保留为对照或回退。
- **确定关系**：保留原生 FEM 几何、ADAS 反应及双源定义；先学习闭合和联合响应。
- **时间核心**：联合 LTC 作为清晰的生成器参照，官方 CfC 作为计算效率候选；不先改公式再找理由。
- **最低先行证据**：编码/源重建、同条件一步可预测性、历史充分性、完整时间对齐和预算。

如果只愿复现每个 marker 的数值轨迹，应优先保留全部历史并优化几何/批量推进，接受其计算规模；不能同时要求有损云压缩又要求任意轨迹完全相同。

**最终判断：这条路线有可复用基础，也有明确可证伪的中间成果；最大不确定性不是“LTC 能不能接收 shard 输入”，而是我们是否能找到足够小、足够可推进、时间定义正确的联合状态。**
