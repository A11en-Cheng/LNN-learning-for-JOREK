# ADR-0016：取消 marker→projection 反组装 gate；Eulerian 矩降级为可选

状态：已接受（2026-09-29）；修订 ADR-0014 第 1 条与"待解决的数据契约"一节。

## 背景

ADR-0014 把"Eulerian 网格投影矩"定为 CfC 的粒子物理子状态，并在 Phase 1.5.1 设了一条
**硬性 gate**：用 `part*.h5` 的 marker 状态反向重新组装 `projections*.h5` 的五个通道，
必须逐帧对齐到机器精度，否则不得进入训练（理由是避免网络把 FEM 截断/归一化误差当物理）。

实际执行结果（证据见 `report/marker-projection-recipe.md` §9、`report/implementation-progress.md`）：

- marker 侧权重链**已独立验证**：logfile 的 `Total generated electrons` 恰为 `Σ_p w⟨Z⟩`
  （同一帧 6.8384e21 vs 6.843e21，0.07%）；密度通道的正确 RHS 形如
  `Σ_p HH·size·w{1,⟨Z⟩,⟨Z²⟩}/n_norm`（`timesteps` 与 `1/(n_steps·timesteps)` 相消，**不除 gather time**）。
- 但把记录解与组装 RHS 对比（局部与全局组装都做过）：`||M·x_recorded||/||b|| ≈ 1e3`，
  且逐 dof 比值跨约 4 个数量级、符号混杂 ⇒ 不是常数因子，而是**结构性差异**。
- 结构性差异的最可能来源是**语义而非代码**：投影的 RHS 是帧内 `n_steps` 个子步的累积
  （粒子在子步间被推进、电荷态演化、marker 群按源分布重采样），而 `part*.h5` 只保存
  帧末快照；此外 n=0 的 cos/sin 配对与 Dirichlet 消元、以及非零滤波项也不在简化模型里。
- 受控实验路径已探明但不能从现有产物闭合：`jorek2_diagno_spi` 只 dump
  `xtime_*`/碎片诊断（与 H5 逐点一致，已验证），**不产出 projections**；投影需要模拟驱动
  `marker_spi_source`，或 JOREK 侧新增逐子步导出（P2 类改动）。

与此同时，路线本身已经不再依赖这条 gate：

- Phase 3 的源项是**教师源**（直接使用记录的 `projections*.h5`），不需要反组装；
- 碎片/烧蚀骨干已被解析路径取代并验证（ADR-0015：逐 shard 中位比 ≈1、log-corr ≥0.98、
  总量误差 ~2%）；
- 闭环（Phase 4.3）若需要自生成源，**确定性路径**（解析烧蚀 + ADAS 电荷态/辐射）比
  学习 marker→投影 的映射更符合"可计算/可迁移"的要求。

## 决定

1. **取消** Phase 1.5.1 的 marker→projection 逐系数反组装 hard gate；它不再是任何阶段的
   阻塞项。已测得的差异与原因记录在案，不再继续追。
2. **Eulerian 矩降级为可选**：从"CfC 的粒子物理子状态前置条件"改为"仅 Phase 4.3 闭环
   自生成源时的一个候选路径"。ADR-0014 的"矩充分性"开放契约随之撤销（不再是阻塞项）。
3. **源项路线定为**：Phase 3/4.1–4.2 用记录投影（教师源）；闭环候选顺序为
   (a) 确定性解析/ADAS → (b) 解析基线 + 有界学习修正 → (c) 粒子侧学习映射（需 P2 级导出）。
4. **投影窗口语义**保留为已知事实与限制：记录值是**单个流体步**的时间平均、帧间隔含
   50 个流体步；教师源按记录值直接使用，闭环阶段按区间平均语义评估（必要时的截断误差
   由 `macroscopic_vars.dat` 交叉校验）。
5. 重新启用的条件：若将来确实需要"粒子状态 → 源项"的可学习映射，且 (a)(b) 两条路径都被
   证伪，则先补 JOREK 侧逐子步导出（P2），再重启本 gate。

## 后果

- Phase 3 可以直接开始（field-only CfC + 教师源），不被 marker/投影契约阻塞。
- 物理内核继续显式计算；学习只承担输运与残差，跨装置可迁移性不受影响。
- 记录在案的残余风险：我们**没有**"Python 从粒子重算 S == JOREK S"的保证；
  该能力在需要时以确定性路径或 P2 导出补齐。
