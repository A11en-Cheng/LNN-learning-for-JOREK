# 显式 marker 局部细分与独立输运历史

原生固定粒子子步在少数低密度陡梯度位置放大定位浮点扰动；经用户确认，增加互斥、非默认的局部二进制细分模式，保持 JOREK 源公式、事件顺序和 base/gather 时钟，不截速度、不改密度下限。每个实际子步共同更新电荷、旧位置五通道沉积、运动和定位，并保存按粒子身份区分的前子步长度与不自动降级的细分历史，以变间隔方向外推代替固定 `1.5/-0.5` 系数。此模式明确偏离 JOREK 固定粒子子步、具有独立配置指纹与检查点契约；因果梯度筛选是经验指标而非稳定性或误差保证，原生模式仍为默认，不能凭少数案例宣称生产资格。

## Consequences

- 原生 `v` 没有保存独立的前采样间隔；首次导入必须显式声明原固定粒子间隔，模型续跑必须保留新增历史，不能重置或从未来场补齐。
- 出生槽重用重置该身份的数值历史；丢失粒子仅贡献已接受区间的沉积。时间平均仍除原 base 窗的实际 gather，而不是按细分次数平均。
- 局部模式模型状态不能静默转换成原生 JOREK restart；模式/config/history 不匹配或预算不足明确失败，不提交部分候选。
- 新模式的细分成本、跨定位差异与更细一级参考误差分别评估；它不改变 ADR-0020 的双源对象、耦合顺序或 NN 源/shard 的梯度边界。

## 末段退出的定向扩展（2026-10-10）

经用户同意，为低密度外边界处的细分超限增加独立、非默认 `local_subcycling_boundary_v2`。只在保存的零邻居外边与完整 cubic 几何上，数值核验冻结方向推进轨迹的首次横向出界时，按末段实际驻留区间共同更新电荷、辐射、三个矩及运动；统一 gather 分母不变，不提高细分上限、不改源强、密度下限或速度。未提供退出证据的细分超限仍失败；普通定位失败、未知负邻居、角点、切向与跨多单元退出不能冒充已核验事件。

这刻意区别于 JOREK 的完整固定步沉积、overshoot 位置与移动后判失（[源码证据](../../report/native-marker-boundary-primary-evidence-2026-10-10.md)）：新模式保存边界位置/局部坐标、负退出单元号及实际末段历史。它是冻结轨迹的驻留时间近似，不是精确连续 ODE 解或 JOREK 原生重放；原生固定模式和原 local v1 保持旧指纹与行为，旧历史不能静默升级。配置绑定实际邻居表及几何；检查点必须保留新模式历史。临终速度与单粒子末段投影的网格/时间收敛误差须单独报告，不能因整个云对照小就宣布普遍精度保证。
