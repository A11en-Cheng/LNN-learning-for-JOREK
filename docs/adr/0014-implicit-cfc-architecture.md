# ADR-0014：隐式 CfC 架构（Eulerian 粒子矩 + 增广源项积分器 + 课程式 teacher forcing）

状态：已接受（2026-09-29）

## 背景

Phase 2.2/2.3 目前是"显式物理骨干 + 小网络修正"。实测表明投影源项是
区间内粒子过程（出生、输运、电荷态演化）的时间平均，不是帧快照的静态函数；
而 JOREK 的粒子状态（`P_imp/x/v/weight`）本身是马尔可夫状态。用户决定把显式约束
改为隐式演化：多模态编码 + CfC 连续时间潜演化 + 物理约束解码。

## 决定

1. **粒子物理子状态采用 Eulerian 网格投影矩，不使用全粒子。** 将粒子的关键物理量
   （粒子数、电荷矩、辐射/冷却权重、空间展宽）按 FEM 基函数投影到 4125 个节点上，
   作为图节点的附加特征，与九场共享同一图拓扑。目的是避免
   `O(N_node x N_marker)` 的注意力开销与 Monte Carlo 噪声。
2. **源项积分器作为 CfC 的增广状态 `A(t)`**：`dA/dt = S_pred(t)`；损失用
   `(A(t+dt)-A(t))/dt` 与 JOREK gather 语义下的时间平均投影比对。由于 CfC 是闭式算子，
   实现采用区间内 `n_sub` 子步 + 求积（子步划分与随机 `alpha/delta` 采样共用）。
3. **课程式 teacher forcing**：阶段 1 每帧用 `part*.h5` 的真实矩初始化、只学单区间；
   阶段 2 展开自回归并做阈值式 Dagger 纠偏（记录纠偏频率与幅度）；阶段 3 在长窗口内
   纯预测覆盖热猝灭，作为 LOO 场景协议的最终评估。
4. **双向、局部、带物理偏置的 cross-attention**：节点->碎片（`R_cutoff` 内的源项注入）
   与碎片->节点（用 FEM 形函数插值局域 `T_e/n_e`，不用 kNN）；相对位置编码包含
   `(dR, dZ)` 与磁通坐标 `rho` 的偏离，以表达沿磁力线的强各向异性输运。

## 待解决的数据契约（实现前必须确定）

- **投影窗口语义**：记录的 `projections*.h5` 是**单个流体步**的时间平均
  （`rhs = feedback_rhs/(n_steps*timesteps)`），而一个输出帧间隔含 50 个流体步。
  增广积分器的训练窗口必须与记录的 gather 语义对齐。候选方案：使用更细的 projection
  cadence；或请 JOREK 侧导出逐步/窗口累计源；或显式量化并接受近似误差。
- **矩集合的充分性**：ADAS 速率依赖逐粒子的电荷态分布与局域 `T_e`，纯压缩矩
  （3-4 个）可能不足以还原能量/辐射通道。最小候选是**逐节点电荷态分辨密度**
  （11 通道）+ 少量附加矩；需用重建实验确定。

## 后果

- Phase 2.2/2.3 的显式 MLP 修正降级为消融组件；主路径改为隐式 CfC。
- 物理内核（ADAS、FEM 沉积、基函数）保持显式计算，学习只负责输运与非局域烧蚀残差，
  以维持跨装置可迁移性。
- 评估沿用 ADR-0012 的 blocked/LOO 协议，并新增按阶段分层的报告
  （注入初期 / 热猝灭 / 平缓演化）。
