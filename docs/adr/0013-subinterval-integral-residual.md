# ADR-0013：插值点物理残差采用子区间积分形式

> **文档隔离（2026-10-04）**：v1 路线历史文件。新架构工作只以 ADR-0018/0019 + roadmap_v2 为准；引用须标注"（历史）"，冲突以 0018/0019 为准（索引见 README.md）。

状态：已接受（2026-09-27）；补充 ADR-0010 第 3 条。

## 背景

ADR-0010 规定插值点的物理残差使用 CfC 的瞬时 `∂u/∂t`。CfC 的解析导数对网络权重敏感，在未完全收敛时
直接代入九方程残差容易产生大梯度与爆炸；而 JOREK 自身的方程装配是弱形式，时间离散使用
`M·Δu/Δt = RHS`，并不需要瞬时导数。

## 决定

1. 插值点物理残差的主路径改为子区间积分形式：取 `t*` 与 `δ = ρ·Δt`（`ρ` 随机，如 0.1–0.3），
   由 CfC 闭式给出 `u(t*)`、`u(t*+δ)`，碎片模块给 `p(t*)`、源项网络给 `S(t*)`，残差为
   `M·[u(t*+δ) − u(t*)]/δ − RHS(u(t*), p(t*), S(t*)) ≈ 0`（或两点梯形）。
   两个状态都由模型给出，不使用数据真值的有限差分。
2. 解析 `∂u/∂t` 仅保留为消融路径；若启用，必须同时启用：全局梯度裁剪与逐残差梯度范数标定、
   `λ_phys` warmup/monitor-only、rate 的空间与子步平滑正则、导数可信度 gate。
3. 残差组装保留 float64 与 `_clamp_physical`；验收仍用扰动单调性与预算闭合，不是零本底。

## 后果

- 物理损失不再依赖瞬时导数的解析路径，梯度条件数显著改善。
- `δ` 的分布成为新的超参数（与 `α` 独立采样），需要登记在 config/checkpoint 中。
- 解析导数路径若日后启用，其稳定化组件也必须有独立消融，不能默默开启。
