# ADR-0010：Physics Loss 只用于随机时间插值点的轨迹修正

> **文档隔离（2026-10-04）**：v1 路线历史文件。新架构工作只以 ADR-0018/0019 + roadmap_v2 为准；引用须标注"（历史）"，冲突以 0018/0019 为准（索引见 README.md）。

状态：已接受（2026-09-24）

## 背景

上一版九场路线把 Physics Loss 当作记录帧上一步回归的正则项（teacher forcing 下的 PDE 残差加权），
并在本该由数据驱动的时刻使用它。该用法已被证伪：对弹丸/源项这类强局部、强非线性过程，它既约束错了
对象（有标签的步进），又让物理项变成缺失源项的替代品。仓库 2026-09-24 的清理已删除该工作流，
ADR-0008/0009 归档。

## 决定

1. 记录帧（有真值的时刻）只用 data loss，保持纯数据驱动。
2. Physics Loss 只在随机采样的插值点 `t* ∈ (t_k, t_{k+1})` 上评估，用于修正无标签的插值与预测轨迹。
3. 插值点的残差必须闭合：场的时间导数来自 CfC，碎片状态来自碎片动力学模块，源项来自源项映射子网络
   （ADR-0011），即 `f(u, ∂u/∂t, S) = 0` 在任意 `t` 都有定义，不用有限差分凑时间导数。
4. 第一批启用全部九个残差，并把五场投影源项接入对应方程；验收用"扰动单调性 + 预算校验"，
   不是"残差本底为零"。

## 后果

- Physics Loss 的权重与本底标定移到插值点；记录帧指标保持纯数据口径。
- 源项网络的精度直接决定 Physics Loss 的可信度，因此 Phase 2 的 gate 先于 Phase 4。
- 与已归档的 ADR-0008/0009 的训练语义不再兼容；旧工作流不恢复。
