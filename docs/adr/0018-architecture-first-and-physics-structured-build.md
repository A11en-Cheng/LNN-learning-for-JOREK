# ADR-0018：架构优先——自生成源、stencil-conv 九场推进与物理结构化验收（2026-10-04）

Phase 3.1b/E10 前置门禁、E7 的 GNN/谱分支、Phase 2 的无记忆结构与 Phase 4 的对照口径。

> **2026-10-08 定向修订**：[ADR-0021](0021-native-state-cfc-window-curriculum.md)
> 修订决定6/12中“参数仅浅层、响应形状不变、深层Jacobian为零”的普遍限制，补充决定13

## 背景

1. 用户 2026-10-04 澄清：v2 的实质是**换架构**，旧 teacher-source 插值结果（推理时吃记录投影
   `projections*.h5`）不是基线、也不再作为对照；它本身不满足新架构的自洽契约。
2. 目标 B 要求训练与推理都按 JOREK 错步格式（场一步隐式、碎片一步显式、源显式）；用户将生成
   **更细粒度的物理数据**（按目标 B 的粒度）来解决当前数据不够密的问题。
3. 用户 2026-10-04 指令：
   - 不要预设基线或性能 gate；首要保证架构具有强的物理性，基线用新架构的新工作确定；
   - 撤销旧 teacher-source 单步 Gate（E10/3.1b）及其 LTC 表达力抢救链条；
   - 空间耦合只做 **stencil-conv**（JOREK 四边形有限元邻接的稀疏矩阵乘法），**明确不用 GNN**，
     不做谱分支；
   - condition 只走物理场景子集 + FiLM/AdaLN；**不做全集 concat，也不设"无 condition"对照臂**；
   - 九场按 **9 个演化场**处理（同一状态契约，不拆 7+2）；
   - `closer` 只在记录帧上定义：判断"模型预测的下一记录帧"更像"真实下一记录帧"还是
     "真实上一记录帧"；不对区间内猜测帧计算 closer。
4. 旧证据中的架构结论仍然有效并被采纳：能量/辐射源通道是历史主导（`roadmap-review-2026-09-29` §2、
   #0016：无 history 的 head 在这两个通道 R² 0.15–0.22，带过去帧历史 0.81–0.96）；
   帧粒度下学习修正学到的多是区间漂移而非模型误差（ADR-0015 的重启条件）。

## 决定

1. **唯一关键路径 = 完成新架构**：自生成源 + stencil-conv 九场推进 + JOREK 错步闭环，
   推理路径不使用任何未来帧记录量。源与场架构作为一体建设，不互为性能门禁。
2. **验收改为物理结构化**：预算（原子/能量/辐射）闭合、离散关系一致、源强有界、
   确定性、无 NaN/坍缩、粒度与时间语义可回溯。**不预设** R²/closer/成本阈值；
   性能基线在架构跑通后用新工作测定并登记。
3. **源对象的语义以 JOREK 源码为准**：被复刻的是 model502 内部驱动场的 `inj_source`
   （Gauss 点逐点沉积、进 RHS、对场显式）；`projections*.h5` 是 marker 投影/导出通道，
   只用于监督与交叉校验，不得作为推理输入，也不得默认等价于内部源（ADR-0016 §6）。
   输出时序（`S_n` 驱动 `u_n→u_{n+1}`；`part{n}` 在 `T_{n−1}`）已由 ADR-0019 核实，
   并写入数据契约（`report/model502-schema-and-source-protocol.md` §3.1a）。
4. **数据粒度按目标 B**：优先使用用户生成的细粒度数据（每流体步或登记子步组的场/碎片/源）；
   细粒度不可得时按帧级自洽推进器交付并显式登记，禁止用帧间插值伪造真值。
5. **空间耦合只做 stencil-conv**：JOREK 四边形 FEM 邻接（size/vertex/形函数/几何权重）构造稀疏
   算子，对 9 场做局部 matmul。禁止 GNN，不做谱分支。
6. **condition 仅物理场景子集 + FiLM/AdaLN**：弹丸质量/速度/角度、`n_spi` 等；不使用 61 维全集
   concat；不设"无 condition"对照臂，改用通道分组 + 分组置换/消融检验。
7. **九场同一契约**：9 个演化通道（现有 `model502-state-v2`），不做 7+2 拆分；
   `Z_j`/`ω` 的椭圆关系（`Z_j=Δ*ψ`、`ω=Δ+Φ`）作为物理一致性检查，而不是替代解码。
8. **记忆是源模块的架构组件**：电荷/密度通道瞬时头，能量/辐射通道必须携带记忆
   （过去投影或潜状态）；学习修正的启用仍受 ADR-0015 重启条件约束，解析-only 为默认交付。
9. **closer 语义（2026-10-04 修正）**：closer 只在记录帧上计算；中间猜测帧不参与 closer。
10. **ADR-0002 / ADR-0012 的相应部分调整**：保留 gated 结构、provenance 与 fail-fast 要求；
    量化性能 gate 在近期工作中不预设，LOO 暂缓为可选泛化评估，不作为前置或 model selection。
11. **stencil-conv 必须执行 JOREK 边界条件（2026-10-04 review）**：提取每节点
    `boundary` 代码 + `freeboundary` + 邻接，映射
    `mod_boundary_conditions.f90` / `mod_boundary_matrix_open.f90` 的 BC；每层输出后
    复位边界节点（Dirichlet 赋值；Neumann/开磁力线用一致的单侧/弱形式口径），
    边界不参与内部写入；磁轴/度量奇异单独处理。验收：多层边界 BC 一致、
    无 NaN 向内传播、内部扰动不改变 Dirichlet 边界值。
12. **condition 只在最浅编码层调制（2026-10-04 review）**：FiLM/AdaLN 仅作用于输入嵌入/
    第一层，深层 stencil 保持纯局部通量交换；恒等初始化（γ=1, β=0）。验收：
    打乱某组 condition 后局部响应函数的形状不变（只允许整体耗散率/驱动强度变化），
    深层 stencil 对 condition 的局部 Jacobian ≈ 0。
13. **B2 的时间积分必须稳定到物理 dt（2026-10-04 B0 实测 + 单位修正）**：显式 stencil
    的几何界（α=1）为 `1/λ_max≈1.7e-7`；物理显式界须逐项折算
    `dt_term=2/(α_term·λ_max)`（η≈2.4e3 稳定；visco/D_par/ZK∥ 在 0.05 下刚性，
    低至 1e-11–1e-13）。B2 采用
    隐式/半隐式局部格式（`(I − dt L) x_new = rhs` 的少量学习型阻尼迭代）或等效稳定
    学习格式（LTC 闭式 + stencil matvec/特征），并在物理 dt 上验收多层不变量；
    stencil 显式 cap 仅作组件安全测试。
    **稳定性 ≠ 保真度**：刚性项的隐式格式必须复现准稳态响应（如沿磁力线剖面），
    不得用对角/标量缩放把模态冻结；B2 验收含准稳态剖面测试；若当前格式只能稳定，
    需升级为预条件 Krylov / 多重网格 / 场向核投影或学习型等效格式。
