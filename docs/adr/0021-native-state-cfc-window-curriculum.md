## 决定与适用范围

1. **保留物理流程**。ADR-0019/0020 的源/场/shard 顺序、双源对象、持久 marker、原始历史与 restart 语义不变。源采样使用已有场端点；流体候选求得后在旧场上更新 shard，再共同提交。新增学习记忆不能替代物理历史。
2. **唯一物理场表示是完整原生系数**。九场全部 degree 联合预测；首轮 H=1，模式轴显式保留。场值和一阶导数从同一组系数及同一原生基函数/几何求值，不能维护互不相容的独立梯度状态。输入的局部场值/梯度是附加观察，不能取代完整系数。系数保留完整不意味着 latent 无信息损失或预测无误差。
3. **零维参数按作用耦合**。场景参数经分组、可追溯的条件编码；局部物理系数经显式消费者；步长/格式/事件标志进入数值时间契约。禁止 run/file ID 捷径和不加区分的全集 concat。允许声明的物理条件影响时间核心和局部响应，不再要求所有参数只能改变整体幅度。条件注入位置、单位、允许影响的消费者须逐项登记；不开放任意全局参数向深层输出的旁路。
4. **核心可替换，状态契约不替换**。同一场步 Interface 内接入 CfC，后续可增加隐式/半隐式或其他学习核心 Adapter；共享窗口、几何、条件、监督与约束才能比较核心。原版 CfC 单元和物理解码包装须分开记录版本。物理零时间恒等（含不推进事件/记忆的 no-op）、单位、边界、有限步长响应与刚性准稳态均需在完整场步验证，不由 cell 名称推定；不要求重新计算状态/源后的非线性整步严格半群。
5. **真实窗口与课程训练**。使用逐步 phaseA 数据的因果历史、完整场/原始增量、派生梯度、物理参数及时间计划。先 teacher forcing 学习局部更新，再逐步增加使用模型场的连续 rollout 长度、减少教师替换，最后纯自回归验收。Teacher forcing 帮助优化，不保证累计误差；scheduled sampling 不等同于有专家重新标注的 DAgger。训练可使用同号教师反馈但必须独立登记退出计划；正式 C0 只用自生成反馈。
6. **误差与加速一起测**。记录逐场/degree、Gauss 场值/梯度、多步累计误差、步长/步长比桶、预算与约束，以及同工作单元的端到端成本。可用真实记录场的梯度做数据监督；不恢复无标签插值伪真值或 PDE 残差训练。稳定不等于保真，不靠冻结增长模态通过验收；不预设性能阈值，不要求移植完整 JOREK 矩阵才能训练。
7. **残差网络（用户补充确认）**。完整原生场通过恒等支路保留，网络输出本步增量，统一约束后执行 `U_next=U_current+ΔU_applied`；空间主干采用残差连接。增量分支归零时应保留已满足约束的输入场值，不能被解码偏置改变；完整零时间no-op还须保留历史、学习记忆与事件时钟。原版 CfC 单元可嵌入残差架构，不为满足“残差”擅自改写其公式。场增量不等于对完整 JOREK 基线解的误差修正，也不与 marker 的有界残差混称；残差结构本身不保证稳定或守恒。
