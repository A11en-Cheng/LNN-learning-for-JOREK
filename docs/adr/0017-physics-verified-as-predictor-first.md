# ADR-0017：物理必须先通过"独立预测器"验证，才能进入 CfC 工作流

状态：已接受（2026-09-30）

## 决定

1. **物理模块在被证明"能预测"之前，不得进入 CfC 训练**（`λ_phys = 0` 仍是默认；
   物理项不设权重、不参与优化）。
2. **验证方式＝独立预测器测试（无神经网络）**：以记录帧 `k` 的**完整信息**
   （当前时刻的零阶系数、场值、以及由 Hermite dof 得到的场梯度）为初值，
   用**完整的 JOREK model502 + marker_spi_source 公式**把状态演化到帧 `k+1`，
   再与记录帧 `k+1` 直接比对。
   - 演化必须是**物理自身的时间推进**（子步进，步长向 JOREK 的流体步看齐），
     而不是"在模型输出上叠加一个残差项"；
   - 源项用记录投影（教师）是允许的**第一版**，但必须显式登记；自生成源是后续消融；
   - 代数约束（`Z_j = Δ*ψ`、`ω = Δ+Φ`）必须每步满足或显式说明如何近似
     （当前图 LSQ 二阶算子已验证到 corr 0.99，但反解是椭圆问题，需单独处理）。
3. **判据（Gate）**：一帧物理演化后的漂移必须**显著小于**同一帧上 CfC 的漂移
   （用同一个 `dR2` 口径比较：`dR2 = 1 − ‖Δ_pred − Δ_true‖²/‖Δ_true‖²`）。
   只有物理漂移优于数据驱动漂移时，物理残差才有资格作为"插值点修正"进入工作流。
4. 数据侧对照实验同时保留：在两步真实时间步之间让 CfC 演化随机 `δt` 再演化到真实值，
   比对真实值——这就是现有的 `two_substep` + `dR2` 测量。
5. 任何"简化"（用部分方程子集、把代数场冻结、用教师源）必须在报告里逐条列出，
   不得默认省略。

## 后果

- 立刻停止一切 λ_phys 调参（gate7/8/9 已证明在当前残差形式下无效且有害）。
- 工作重心回到两件事：① 把物理 RHS 补全到与 JOREK 一致（含弱形式/系数完整性）；
  ② 建立上面那个"物理 vs 数据"的独立比对实验，并把它作为 Phase 4 的新 Gate。
- `probe_grad_scales.py`（梯度推力尺子）与 `check_fem_second_order.py`（算子判定标准）
  保留为工具：前者用于将来任何进入工作流的损失项配平，后者守算子正确性。

## 首个独立验证结果（2026-09-30，`tests/check_physics_rollout.py`）

以记录帧 `k` 为初值、**无神经网络**、用我们的物理 RHS 显式推进到帧 `k+1`，
与记录帧比对（`Z_j`/`ω`/`Φ` 冻结在帧 `k`，源用记录投影）：

| 场 | 物理演化 dR2（4 个区间中位） | CfC（gate6）dR2 |
|---|---:|---:|
| **psi**（感应方程） | **+0.97**（区间值 0.69/0.98/0.97/0.97） | +0.08 |
| rho / rho_imp / T_i / T_e / v_par | **显式积分不稳定**（步长受 κ∥~1e5–1e6 限制，稳定性上限要求 `Δτ ≲ h²/2κ ≈ 1e-10`） | 0.39/0.43/0.39/0.25/−0.02 |

两条结论：

1. **感应方程（ψ）独立验证通过**：物理演化把 ψ 的下一帧预测到 dR2≈0.97，
   比 CfC 高一个数量级。说明"物理作为预测器"这条路在可显式积分的方程上是成立的。
2. **含扩散/传导的方程必须隐式求解**：这不是精度问题而是**刚性**问题——
   JOREK 每步解矩阵正是为此。因此"完整物理演化"的前提是**弱形式 + 隐式时间推进**
   （也正好是算子噪声与梯度放大的根治办法）。

当前已知的**未补全项**（在通过独立验证前必须补齐或显式登记）：
密度/杂质方程缺粒子源项；电子能量方程的 `rad_sink/dE_ion` 目前用记录投影；
`marker_spi_source` 的自洽耦合未接入；代数场 `Z_j`/`ω` 需每步由椭圆求解给出
（当前冻结）；时间推进为显式（刚性项需要隐式）。

## 刚性项与"负值"处理（2026-09-30，用户指路后核查 JOREK 源码）

**JOREK 对异常/负值的两套机制**（照抄，不自己发明）：

| 位置 | 机制 | 源码 |
|---|---|---|
| 流体 T / ρ（进入输运系数） | **指数型光滑下限**：低于 `L1+L2` 时 `T ← L1 + L2·exp((T−(L1+L2))/L2)`，阈值由 `T_min_neg`/`T_1`/`rho_min_neg` 与系数给出；并同时提供一/二阶导数供矩阵装配 | `models/corr_neg_include.f90`（`corr_neg_temp1`、`corr_neg_dens`）、`models/model502/mod_elt_matrix.f90:482-495` |
| marker/源（电荷态、组份、源分布） | **硬下限到 0**：`Z_imp<0 → 0`、`P_tmp(iZ)=max(P_tmp,0)`、`f=max(P·dv/P_norm,0)`；除法用 `max(...,1d16/1d12)` 保护 | `particles/examples/marker_spi_source.f90:521, 563/569/581, 815, 510/512` |
| 曾经的硬检查 | "RHS 出现负值/超范围就 stop" 的检查**已被注释掉**（说明负值在正常演化里会出现，不能当致命错误） | 同上 `678-702` |

**滚出测试中的实现与实测**（`tests/check_physics_rollout.py`）：

1. 记录投影源包含负值（实测 `rad_sink` min −3.5e-6、`Z_eff` min **−1.07**、`Z_imp` −0.18）
   ⇒ 已按上表**下限到 0**。
2. 温度用 JOREK 的光滑下限（`smooth_floor`，默认阈值 1e-3）替代硬 clamp。
3. 时间推进改成 **IMEX 分裂**：对流/交换/源显式，传导（κ∥~1e5–1e6）隐式，
   隐式算子用矩阵自由 CG（`(I − (Δτ/n)·L_cond)T_new = …`）。
4. **实测仍发散**，诊断给出确切瓶颈：能量方程右端 **rms 1e3–1e4**（`d(n_iT_i)/dt` 4.1e3、
   `d(n_eT_e)/dt` 1.2e4）而场本身 O(0.1)；条件数 κ∥/κ⊥ ~ 1e11，
   **无预条件 CG 不收敛**（首个子步 T_i 即出现非有限值）。
   ⇒ 下一步必须**显式组装 `L` 与 `L∥` 稀疏矩阵并直接求解**（4125×4125、~30 nnz/行，
   直接稀疏 LU 约 0.1–1 s/步，与 JOREK 每步解矩阵同构），或做沿磁力线的专用预条件。

## 决策（2026-10-01）：物理损失暂停，回到 data-only；物理参照走离线 JOREK

**背景**：自建独立物理演化器（逐场算子分裂 + 弱形式算子）经过一轮系统修补后仍不稳定。
根因是**结构性**的：JOREK 把九个变量放进**同一个隐式矩阵**同步求解，而我做的是逐场分裂解；
分裂误差在刚性项（κ∥~1e4、h~1cm）下每步放大 ~1e4 量级 ⇒ 无论补项/钉边界都会在几个子步内炸。
按症状修（传导系数封顶、对流隐式化、子步=tstep、TG 稳定化、源项 R 权重、压强 alpha 闭合与符号、
弱形式 RHS）都做完了，收益递减。

**决定**：
1. **物理损失暂停**（`λ_phys = 0` 为默认），训练恢复 **data-only** 主路径
   —— 残差网络 + 动力学配平 loss + 一/二阶导数特征这套**保留**（这是数据侧的既定修正，
   与物理损失无关）；只去掉物理项。
2. **不做任何 JOREK 计算**（用户 2026-10-01 澄清：暂定方向是**直接用纯 data 训练**，
   而不是用二进制算物理参照）。物理的独立验证因此**整体挂起**，等将来确有需要再重启；
   相关工程准备（`single_frame_restart.sh` 的隔离/改写外壳、pitfalls #40/#41 的两条文件安全结论）
   保留备查，不再执行。
3. **整体隐式矩阵（选项 1）** 另立工作项：按 `amat_ij`(1..9) 组装 [9N×9N] 稀疏系统，
   与 JOREK 同步求解同构；在它完成之前不再继续逐项修补。
4. 已确认无误并保留的成果：`src/physics/fem_weak.py` 的算子族（P1 拉普拉斯/平行/各向异性/
   对流/标量刚度，全部有验证脚本）、`weak_vorticity.py`（弱残差 0.370 ✅）、压强 alpha 闭合、
   传导系数封顶、源项 R 权重、`tstep` 子步——**这些是将来物理损失的可用地基**。
