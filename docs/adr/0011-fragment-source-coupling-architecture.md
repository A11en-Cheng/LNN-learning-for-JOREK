# ADR-0011：场-碎片-源耦合采用统一碎片编码、混合动力学与源项映射子网络

> **文档隔离（2026-10-04）**：v1 路线历史文件。新架构工作只以 ADR-0018/0019 + roadmap_v2 为准；引用须标注"（历史）"，冲突以 0018/0019 为准（索引见 README.md）。

状态：已接受（2026-09-24）；第 2 条的"解析-only 对照"已在 ADR-0015（2026-09-29）收口。

## 背景

JOREK 的 SPI 模型（`models/pellet_module.f90`）已有解析的碎片运动/烧蚀骨架：位置推进、RKT 加速度
（Chalmers 系数）、半径侵蚀、NGS/Parks 烧蚀标定，以及 `(u_k, p_k) → S_k → u_{k+1}` 的错步显式耦合。
数据侧：10 个 2D run 全部启用 SPI，都有 marker/projection/field，并在注入时刻 `t_ns` 之后
导出 shard 级状态与逐时间步烧蚀序列（共约 1663 个 post-`t_ns` 帧，每个 run 只有一次注入）。
纯解析无法吸收模型误差；纯学习在闭环中容易漂移，且可用的事件窗口有限。2D 数据只有单一环向模，
FFT/谱架构在本阶段没有内容。

## 决定

1. `p(t)` 使用统一集合编码：shard 级字段与 marker 归约特征共用一个 permutation-invariant 编码器
   （含存活 mask），10 个 run 都可参与；shard 级监督来自各 run 的 post-`t_ns` 帧。
2. 场→碎片一步为混合动力学：JOREK 解析骨干 + 学习修正（乘性烧蚀率修正、可选力修正）；
   先做解析-only 对照，再决定修正的必要性与幅度。
3. 碎片→源项用源项映射子网络：输入碎片编码与碎片邻域的局域场，输出五场投影；NGS/Parks 解析值为基线，
   网络学修正。
4. 当前范围只做 2D（`ntor=1`，单一环向模）；`ntor11` 的环向模耦合另行立项。
5. 与 ADR-0005 的关系：主状态模型仍只以九场原生量为学习目标；本 ADR 的两个模块是辅助闭包，
   允许以导出量（五场投影、碎片状态）为监督目标。

## 考虑过的方案

- 纯解析/硬算 `update_spi`：精确但无法吸收模型误差，且必须复刻全部 namelist 分支。
- 纯学习 `p → p'`：灵活但每个 run 只有一次注入事件（约 1663 个可用帧），闭环稳定性没有保障。
- Fourier/谱架构：2D 只有一个环向模，FFT 无内容；3D 时再讨论模耦合。

## 后果

- Phase 2 产出独立的源项与动力学模块，Phase 4 的 Physics Loss 依赖它们的精度。
- 闭环训练必须显式区分教师源与自生成源，防止标签泄漏。
- 生成数据使用的模型已核对：`spi_abl_model = 3`（Parks/NGS + 非局域烧蚀）、
  `spi_rkt_model = 6`（PELOTON JET 标定，见 `models/pellet_module.f90`）。
- `ntor11` 数据与 EXL-50U 跨装置验证被排除在本 ADR 范围之外。
