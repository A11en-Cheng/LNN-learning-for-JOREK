# 标量 vs 矢量场预测对比

## 概述

本目录提供两个版本的 LNN 训练：
1. **标量预测**：预测速度大小（`laminar_vortex_lnn_training.py`）
2. **矢量预测**：预测速度分量 u_x, u_y（`laminar_vortex_vector_lnn.py`）

## 对比分析

### 1. 问题设置

#### 标量版本
```python
# 输出：速度大小
|V| = √(u_x² + u_y²)

特点：
- 输入维度：16
- 输出维度：1
- 预测目标：单一标量值
```

#### 矢量版本
```python
# 输出：速度分量
[u_x, u_y]  (在空间采样点处)

特点：
- 输入维度：128 (2 × 8² = 2 × 64个采样点)
- 输出维度：128 (完整矢量场表示)
- 预测目标：完整2D速度场
```

### 2. 数据量对比

| 指标 | 标量版本 | 矢量版本 |
|------|---------|---------|
| 时间快照数 | 150 | 149（预测一步） |
| 空间采样点 | 简化特征 | 8×8 = 64点 |
| 输入特征维度 | 16 | 128 |
| 输出维度 | 1 | 128 |
| 总参数规模 | 小 | 中等 |

### 3. 训练性能对比

#### 损失函数

| 指标 | 标量版本 | 矢量版本 |
|------|---------|---------|
| 初始损失 | 1.068e+00 | 5.666e-01 |
| 最终损失 | 1.684e-06 | 3.817e-05 |
| 最佳损失 | 1.615e-06 | 3.772e-05 |
| **损失下降倍数** | **634,261x** | **14,845x** |

**解释**：
- 标量版本的损失下降更剧烈，但因为任务简单
- 矢量版本需要学习更复杂的高维映射，但仍然收敛良好
- 矢量版本的"绝对损失"更高，但这是因为有128个输出维度

### 4. 预测精度对比

#### 标量版本
```
平均绝对误差 (MAE): 9.353e-04
最大绝对误差: 4.665e-03

```

```
  - MAE: 4.130e-03

```

### 5. 物理意义

#### 标量预测的优点 ✓
- 预测单一标量值，模型复杂度低
- 对于全局流场特征（如总动能、涡旋强度）很有用
- 学习速度快，收敛稳定

#### 标量预测的限制 ✗
- 丢失方向信息
- 无法重建流场结构
- 不适用于进一步的流动仿真

#### 矢量预测的优点 ✓
- **完全保留流动信息**，可重建完整流场
- 能够预测方向 → 0.4°的方向误差表示预测方向精确
- 适用于多步递推仿真（可用预测输出作为下一步输入）
- 可用于涡度、流函数等导出物理量计算
- 更接近实际 JOREK 应用（需要空间解析的流场）

#### 矢量预测的复杂性 ✗
- 模型需要学习 128 维输出映射
- 训练过程更复杂，需要更多参数
- 计算成本更高

### 7. 应用场景选择

#### 使用标量版本 📊
```
✓ 快速原型开发
✓ 全局特征预测（总能量、总流通量等）
✓ 分类/聚类任务（流动状态判断）
✓ 实时计算（轻量级模型）
```

#### 使用矢量版本 🌪️
```
✓ 完整流场重建
✓ 多步递推预测
✓ 涡度、压力等导出量计算
✓ 与 JOREK 耦合仿真
✓ 流动可视化和分析
✓ 需要保留空间结构信息
```

### 8. 技术细节对比

#### 特征提取

**标量版本**：
```python
# 简化特征：采样点的速度幅值
features = [|V|₁, |V|₂, ..., |V|₁₆]
```

**矢量版本**：
```python
# 完整矢量场采样
features = [u_x₁, u_y₁, u_x₂, u_y₂, ..., u_x₆₄, u_y₆₄]
           └─────────────────────────────────────────┘
                      128 维特征向量
```

#### 损失函数设计

两个版本都使用 MSE，但含义不同：

```python
# 标量版本
Loss_scalar = MSE(|V|_pred, |V|_true)

# 矢量版本
Loss_vector = MSE([u_x_pred, u_y_pred], [u_x_true, u_y_true])
```

矢量版本的损失同时约束 x 和 y 分量，提供更严格的约束。

### 9. 进一步的扩展方向

#### 从标量到矢量
```
标量 (1D) → 矢量 (2D) → 张量 (3D)
```

#### 融合方法
```python
# 可以组合两种方法：
# 1. 主要用矢量模型预测完整场
# 2. 额外的标量模型监督全局特征
# 3. 多任务学习框架
```

#### 高级技术
```
✓ 条件矢量LNN：pred = LNN(u_x, u_y | global_state)
✓ 自回归预测：使用前面的预测作为下一步输入
✓ 物理信息约束：加入涡度守恒、质量守恒等约束
✓ 多尺度预测：同时预测不同分辨率的场
```

## 推荐方案

### 对于 JOREK 应用：**使用矢量版本** 🎯

理由：
1. JOREK 是等离子体流动模拟，需要完整的空间分辨流场
2. 下游应用（涡度计算、压力重建等）需要 u_x, u_y 分量
3. 多步递推预测必须保留完整信息
4. 0.4° 的方向误差表示方向精确性很好

可进一步改进：
- [ ] 增加到 16×16 或 32×32 空间分辨率
- [ ] 扩展到 3D 矢量场 (u_x, u_y, u_z)
- [ ] 加入涡度作为额外输出
- [ ] 实现自回归多步预测
- [ ] 与真实 JOREK 数据集对接

---

**总结**：
- 标量版本：简洁高效，适合特征预测
- 矢量版本：信息完整，适合物理模拟

两者都验证了 LNN 的强大能力！
