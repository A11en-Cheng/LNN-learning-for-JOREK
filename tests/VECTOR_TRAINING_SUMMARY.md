## 🔬 物理模型

### 二维层流-涡流系统

```
基础流: 剪切层
  u_x(y) = U₀ tanh(y/δ)    [层流背景]

扰动: 涡对动力学
  • 反向对称配置（+涡和-涡）
  • 自我平流: 涡随平均速度移动
  • 粘性衰减: σ(t) = σ₀√(1 + 4νt/σ₀²)
  • 感应速度: 使用高斯涡核计算

参数:
  - 域大小: [0, 2π] × [-π, π]
  - 网格: 32×32
  - 粘度系数: ν = 0.01
  - 涡对强度: 1.0
```

```
模拟 JOREK 的自适应时间步长:
```

## 📞 常见问题

**Q: 为什么矢量版本的损失数值更大？**  
A: 因为输出维度更多（128 vs 1），但相对而言精度仍然很高。关键指标是组件 MAE 和方向误差。

**Q: 能否进一步增加空间分辨率？**  
A: 可以，将 `spatial_samples` 改为 16 或 32，但需要增加隐层大小和训练轮数。

**Q: 为什么没有加显式的 dt 输入？**  
A: CfC 单元通过学习隐含的时间常数来适应变化的 dt，这是其优于 RNN 之处。

**Q: 如何用于多步递推预测？**  
A: 使用当前预测作为下一步的输入，但需要谨慎处理误差累积。
