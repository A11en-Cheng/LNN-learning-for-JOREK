# 二维层流-涡流 LNN 训练

## 概述

本目录中的 `laminar_vortex_lnn_training.py` 实现了一个完整的学习神经网络（LNN）训练流程，用于预测二维层流-涡流的时间演化。

## 文件说明

### `laminar_vortex_lnn_training.py`

这是主要的训练脚本，包含以下核心部分：

#### 1. **物理模型**（`LaminarVortexFlow` 类）

实现了一个二维流体力学模型：

- **基础层流**：剪切层 $u_x = U_0 \tanh(y/\delta)$
- **涡对**：两个反向涡旋对对称排列，随时间演化：
  - **自传播**：涡对以平均速度平流
  - **衰减**：涡核随粘性扩散而衰减，$\sigma(t) = \sigma_0 \sqrt{1 + 4\nu t/\sigma_0^2}$
  - **感应速度**：使用高斯涡核计算诱导速度场

#### 2. **数据生成**（`generate_laminar_vortex_dataset` 函数）

生成训练数据集的关键特性：

- **不规则时间采样**：模拟 JOREK 的自适应时间步长
  - 时间步长 $\Delta t \in [0.02, 0.17]$，平均 $\approx 0.097$
  - 150 个时间快照，覆盖 0 到 8.0 时间单位

- **特征提取**：从二维速度场中提取 16 维特征
  - 空间采样方法：降采样速度分量
  - 归一化并与噪声混合（5% 测量噪声）

- **目标值**：速度大小的时间演化

#### 3. **LNN 模型**（`LaminarVortexLNN` 类）

- 使用 Closed-form Continuous (CfC) 单元
- 输入大小：16（提取的特征）
- 隐层大小：32 个神经元
- 输出大小：1（标量预测）
- 返回完整序列预测

#### 4. **训练过程**

- **优化器**：Adam (lr=0.002)
- **损失函数**：MSE
- **训练轮数**：3000 epochs
- **设备**：自动检测 CUDA（优先使用 GPU）

## 扩展建议

### 1. 增加流场复杂性
- 多个涡对或涡簇
- 非对称涡配置
- 外部力场或边界效应

### 2. 改进特征表示
- 使用 POD（Proper Orthogonal Decomposition）提取主要模式
- 自编码器维度缩减
- 物理信息编码（如涡度、流函数）

### 3. 扩展到 3D
- 从 2D 层流-涡流到 3D 涡环动力学
- 包含分层效应

### 4. 与 JOREK 集成
- 使用真实 JOREK 模拟的输出数据
- 验证 LNN 对等离子体动力学的适用性

### 5. 模型改进
- 尝试多输出预测（同时预测 u_x 和 u_y）
- 使用物理信息神经网络（PINN）加入守恒律
- 递推预测与单步预测的比较

## 物理解释

该训练展示了 LNN 对以下物理现象的学习能力：

1. **涡旋衰减**：粘性扩散导致涡核增大、强度减弱
2. **涡对平流**：涡对以平均流速运动
3. **速度演化**：整体流场速度大小随时间单调递减（涡对衰减主导）
4. **不规则采样鲁棒性**：LNN 能够适应变化的 Δt
